# 课堂轮数与设置说明

作者：ahui。2026-10-21。产品版本 1.0.0。

补充：只有一个词时直接调整该词轮数，不显示词语选择和批量面板；多词批量分类只列实际存在且与全部范围不同的选项。隐藏不适用入口不删除保存值，规则见 [课堂上下文与信息精简](13-课堂上下文与信息精简.md)。

## 现状与修复约定

编辑器已有每词 1～8 轮和锁定／手动来源；课堂设置遗漏轮数入口。说明主要依赖常驻文字，缺少可悬浮、聚焦及触控查看的统一入口。本轮复用正式编排，不新增教学规则、模型能力或存储协议。

- 课堂开始前增加「每词练习轮数」，默认保留课件中每个条目的原轮数。逐词选择后修改，合法值预览待保存编排，底部完成设置时统一应用；同名词按条目 ID 区分。手动值可逐词明确修改，锁定值须回编辑器解锁。
- 提供全部／普通词／重点词的统一调整。先显示实际可调整数量及受保护数量，再通过底部完成设置统一应用；默认跳过锁定及手动轮数，教师可明确选择包含手动值，锁定始终保留，不静默覆盖。逐词调整标为本课本地保存的手动值；支持撤销最近一次调整。
- 空白、小数、超范围保留原输入并就近解释；未处理的逐词非法输入阻止开始。可恢复该词当前值，不以旧值悄悄开局。后续统一校验见 [课堂设置校验与布局](14-课堂设置校验与布局.md)：批量非法值阻止完成，合法草稿可通过完成设置统一保存；未完成变更阻止课堂继续，收起不丢失草稿；明确放弃不影响已生效安排。
  课中未完成输入同样阻止继续／切词；关闭后重开仍保留。主动结束课堂放弃未完成输入，重玩使用已应用的安排，不被隐藏草稿阻塞。
- 修改使用正式 compileWordBeat 校验并重新生成时间轴及音乐位置，失败不安装部分结果。显示精确到十分之一秒的编排时长，不包含教师等待。两种跟读模式的一轮是示范＋跟读；齐读的一轮由总拍数决定，4 拍／每次 2 拍／2 轮表示读 4 次，不改变每轮读 2 次的规则。
- 根据后续补充的应急课堂要求，轮数也可课中调整：当前词保留已开始的全部轮次，进入另一词的首阶段才安装新安排；重读当前词仍用旧安排，最后一词的修改在重玩或整课循环时生效。暂停、等待和错误状态不得因应用而自动发声。待生效的轮数与之后的节奏修改合并，不互相覆盖。重玩及回到开始页保留成功保存的本地设置；显式恢复原值见 [本地保存与统一完成](15-课堂设置本地保存与统一完成.md)。永久修改与导出使用编辑器，课堂设置不写回原课件。
  练习中打开设置默认定位正在练习的词，避免应急操作误改第一词；未完成输入优先恢复到对应词。
- 相关设置标签提供统一说明按钮：悬浮／聚焦显示，点击可固定，Esc 先关闭说明而不关闭设置面板；可移动到说明上阅读。滚动、失焦、关闭和卸载清理浮层及监听；视口内避让，支持全屏课堂和离线 HTML。
- 轮数、拍数、推进、循环、节奏、恢复准备、展示与声音等用教学语言说明。错误与影响范围仍就近常驻，不隐藏在帮助中。

## 验收与边界

后续增加的课堂英文／释义临时调整与声音边界遵循 [课堂临时词语调整](18-课堂临时词语调整.md)，与轮数、拍数共用选词和唯一完成入口；保留原文来源，支持明确增删和组内排序；结构改变后课中完成返回开始页。

后续课堂设置已明确补齐自主齐读的每轮总拍数、每次朗读占拍及词间间隔，不能仅显示只读摘要；约束与验收见 [课堂拍数与朗读次数复查](17-课堂拍数与朗读次数复查.md)。四拍读两次是每次占两拍，不能误当成末词被缩短。

拍数与轮数采用相同的直接编辑方式：左侧搜索选择词，中间调整正文、类型、轮数、每轮总拍数和每次朗读占拍；右侧选择实际范围后直接修改统一目标，不再先勾选字段。范围中的共同值直接显示，混合值注明「各词不同」，未编辑不产生待保存修改。拍数每项的「还原」只取消该项统一目标，另一项继续保留；非法空白不能借此变成不修改。字段保护、朗读摘要和底部统一完成仍沿用同一约定。

设置按本课真实状态说明：声音通道依据实际编排中使用的音频标为「示范」「口号」或「示范 / 口号」，不因保留其他模式的素材而显示未使用声部；共用原有 voice 音量字段。运行中的「继续前准备两拍」保留禁用约束，就近显示「仅课前调整；需要修改请回到开始页」，不用悬停帮助作为理解禁用原因的唯一途径。展示、推进、循环、声音测试及恢复原值均保留其原有用途，不因低频使用而删除。

根据用户后续强调，完成入口修复后再对唯一首发游戏全面回归：开场、三种模式、两种展示、拍位词槽、完整轮次、等待与自动推进、导航／重读／调速、暂停恢复、错误恢复、结算重玩、课堂设置及离线交付。保留既有科技主题、全息舞台、粒子与击拍效果；不以额外装饰或大模型按钮替代真实辅助。课堂调整的智能体验由保护规则、实际时长、朗读摘要、就近解释、明确生效时机与撤销共同体现。

检查三种模式、1／8 轮、非法输入、锁定／手动保护、重点词范围、撤销、先改 BPM 再改轮数、准备时长、首次开局、重玩及恢复原值。检查两拍一次朗读不重复触发、对拍音乐映射及暂停恢复。720×480、911×480、1366×768 实际观察帮助浮层、焦点、滚动和词槽；真实离线文件运行。执行类型、静态、单元、浏览器和构建检查，报告实测范围，不以模拟音频设备证明物理同步。
