# 课堂设置本地保存与统一完成

作者：ahui。产品版本保持 1.0.0。

## 已复现问题与范围

上一版在离线文字领读文件中把节拍音量改为 35%，完成后刷新恢复 20%，本地没有保存记录。BPM、批量轮数需要分别点击应用，教师容易遗漏；运行中结束入口藏在设置里，开始页缺少全屏，顶部词序偏小。复现截图与本轮验证放在 `validation/classroom-persistence-review/`。当前没有 `.git`，修改前保护了 197 个文件并记录 SHA256；不初始化仓库、不提交、不推送。

## 统一完成与草稿

当前课堂词语管理采用独立本地版本5，保存正文、词表顺序和适用教学参数；旧版本1～4严格只读继承规则、显式配音回退及生效边界见 [课堂临时词语调整](18-课堂临时词语调整.md)。下文旧协议作为兼容历史，不代表新完成仍写版本2。

齐读拍数与词间间隔的后续补齐、独立本地版本 3 及 v1／v2 继承契约见 [课堂拍数与朗读次数复查](17-课堂拍数与朗读次数复查.md)。本文 v2 描述保留为已交付兼容规则；新完成同时保存齐读总拍数、每次占拍及间隔，仍只用一个完成入口。

- 课堂设置只有底部「完成设置」负责提交。每词轮数、统一轮数、BPM、推进、循环、恢复准备、显示及全部声部音量一起校验、编排、保存并应用，不再提供分散的应用按钮。
- 编辑期间显示真实待保存预览，包括批量调整后的逐词轮数、摘要和时长，保持课堂暂停；收起／Esc 保留当前草稿但不保存，未完成变更需回设置完成或明确放弃。声音测试可试听合法草稿，不改变课堂进度。
- 批量轮数只有教师编辑后才进入待保存安排；显示实际范围、变化数量和手动／锁定保护。仅选择范围不产生修改，未输入目标时随范围显示其真实共同值或混合空值；编辑目标后再切范围才保留该目标并重新预览。逐词修改记为手动值，批量默认保留；教师明确勾选包含手动值时才覆盖，锁定始终保留。后发生的逐词修改先接收合法批量候选再修改，不能被先前批量目标反向覆盖。无变化操作不产生确认。非法原始输入保留，就近提示；不能用旧数值完成。整课编排失败、存储失败均保留面板与输入，不显示保存成功。
- 课中完成后，轮数变化从下一词或重玩生效，当前词与重读保留原轮数；单独改 BPM 沿用既有暂停／等待边界。对拍音乐不能只改画面 BPM。恢复准备仍仅课前可改。完成后不自动继续。
- 新建／新增词条初始均为一轮，包括重点词及三种模式；已有课件和已保存设置不覆盖。教师主动使用预设、建议或设置仍可明确改变轮数，原有手动／锁定保护不变。
- 制作向导区分「当前安排」与预设目标：当前轮数从真实词条统计；卡片中的普通／重点轮数明确标为预设目标，确认差异后才改变实际安排。不能仍提示新课已按旧的重点加强轮次编排。

## 本地保存契约

- 成功完成时以 `localStorage` 的单键写入保存全部课堂设置：按条目 ID 的轮数和来源、BPM、推进、整课循环、继续前准备、展示、释义、舞台特效、前后词预告、示范／口号、节拍及音乐音量。隐藏但合法的声部值保留。
- 新记录使用独立命名空间及本地版本 2，按课件 ID 隔离，同时核对原课件修订、正文和本课正式依赖的素材元数据指纹。素材指纹只纳入本课实际引用的资源；素材库中无关声音或音乐增删，不让本课设置过期。内容指纹仅用于检测配置过期，不作为安全鉴权；保存记录本身也必须严格校验并重新通过正式整课编排。课件内容、模式、规则、本课音乐或修订变化时不自动套用旧记录，明确告知使用原课件设置。未知版本、损坏或超限记录同样不应用。
- 已交付本地版本 1 按其原全素材库指纹校验：仍匹配时只读恢复，下一次教师完成设置再写为版本 2；不能核实时保留旧记录并说明未恢复，不猜测或静默迁移。旧程序不认识版本 2 时使用原课件设置，不删除记录；课件、包格式与运行核心版本不因本地偏好修复改变。按用户最新清理要求，发布目录仅留最新打包，回滚使用受保护源码重新构建与原课件。
- 不保存播放进度、分数、计时器、音频字节、原素材路径、未完成输入、批量草稿或撤销快照；不写回原课件或 HTML。每份记录上限 256 KiB，一课一个键，重复完成覆盖同键；没有后台任务或持续写入。
- 同一浏览器、同一来源的同一课件重新打开和回到开始页恢复最后成功保存的设置；播放从头开始。重玩清空进度，保留当前已完成设置。复制课件有新 ID，不串用；课件包仍保存编辑器中的课件数据，不携带浏览器偏好。
- 「恢复课件原始设置」先说明清除本课本地记录并回到开始页，确认后清除且释放音源、时间轴、草稿和撤销；其他课件不受影响。取消无副作用。删除失败不冒充恢复成功，允许重试。
- 禁用存储、隐私模式限制、配额不足等读取／写入／删除失败要说明并允许重试；也可明确选择仅本次使用继续上课，不伪称已保存。浏览器清理数据会删除记录；不同浏览器／配置目录不共享。`file://` 的存储作用域由浏览器决定，移动文件、换目录或换电脑不保证沿用，界面给出简短说明。
- 多窗口不强制同步正在上课的安排；最后一次成功完成写入供下次打开读取，避免另一窗口打断课堂。

## 课堂入口与展示

设置分区导航只滚动设置正文并对齐分区起点，小屏长分区不能从中部进入而隐藏标题与摘要；就近定位错误字段仍以该字段可见为准，不强制把用户带回分区顶部。所有定位均保留外层弹窗、标题和完成操作的位置，不能把外层隐藏溢出容器一起卷走。

直接结束课堂且没有未完成设置时，只反馈真实的结束动作，不显示“已放弃未完成输入”。确实存在未完成设置且结束时放弃，才明确说明放弃并保留上次完成的安排。

运行中底部直接提供「结束课堂」，无需进入设置；结束显示真实结束状态，允许重玩。桌面预演的「返回编辑」放在运行页顶部，底部与离线课堂保持相同的七个控制，避免 720×480 下折行挤占教学内容。开始页和结算页提供全屏／退出全屏，与运行中使用同一处理及失败反馈。顶部词序提高字号和字重，当前词仍突出；中央单词、释义及下方词槽保留，低高度／小屏不遮挡主要控制。

实际 Tab 复查发现：说明浮层在按钮失焦时同步卸载，会干扰浏览器的下一个焦点选择，导致模态焦点回到开头。共用说明组件在本次焦点切换完成后再清理浮层，仍保留 Esc、外点、滚动和卸载清理；验收需遍历真正不同的输入和底部按钮，不能只统计 Tab 按键次数。

## 验收、兼容与回滚

长口号试听仅在 1.8 秒后停止测试节拍和音乐，口号音量继续遵循教师最新合法输入，不能被旧回调恢复成开始试听时的值。放弃草稿或回到开始页后，统一轮数使用当前已完成设置的真实值；混合轮数明确为未输入的批量目标，不把固定的 1 轮伪装成当前安排。未编辑的混合值不阻止完成或上课。

使用三种模式实测保存后刷新、关闭浏览器进程再用相同配置目录重开、回到开始页、重玩、不同课件、课件更新、损坏记录、存储失败及恢复取消。回归非法 201 音量、1～8 轮、BPM、批量范围和锁定保护；全部设置统一完成，无需额外应用。验证直接结束、全屏、720×480／911×480／1366×768 布局、键盘焦点、四词槽及运行中动态效果。实际离线 HTML 在断网且无开发服务器时验证。

运行规则和课件数据协议不变，本地偏好有独立版本；无新依赖。旧 HTML 不会自动更新，需使用本轮新导出的文件。旧核心不认识本地记录版本 2 时不套用，保留记录且不修改课件数据；回滚使用旧安装包／文件，或按受保护基线恢复本轮源文件。Java／MyBatis 专属规范不适用于当前 React／TypeScript／Tauri/Rust 项目。
