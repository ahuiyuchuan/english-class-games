# 最快导出一个「单词节拍」小游戏

适用：Windows 版 English Class Games 1.0.0。作者：ahui。

主要按1920×1080设备使用与验收；其他窗口尺寸保留基本兼容。

第一次使用，先用示例词表跑通一次。无需配置模型服务，也不用另装英语语音包；新版安装包已带中英离线配音。

## 照着这 8 步做

1. **打开软件，点「智能制作」。**
2. **点「使用示例词表」，再点「整理并预览」。** 示例有表头，软件会识别每一列，不用逐列填写。
3. **检查英文和中文，点「确认内容，下一步」。** 这个按钮在校对区右上方。全部保留就不用操作勾选框；要改原文，点「查看或修改原文与列设置」。
4. **填课件名称，选练习模式。** 第一次可保留「常规巩固」和默认参数，不需要计算拍数或时长。
5. **点「一键制作」，等待制作完成。** 配音跟读会使用内置声音；已有声音能复用就不会重复制作。有错误时按页面提示修正后重试。
6. **点「预演课件」。** 开始前可点「课堂设置」调整推进、画面和音量，再点「完成设置」→「开始课堂」。看一下单词、释义和节奏，试听声音。检查后点「返回制作」。
7. **点「导出课堂文件」→「检查并导出」。** 保留默认的当前版本；想以后继续修改，就勾上「同时保存可编辑课件包」。按弹出的保存窗口选择位置。
8. **打开刚导出的 `.html` 文件，再试一次「开始课堂」。** 使用 Edge 或 Chrome。确认无误后把 HTML 复制到教室电脑；文件已带需要的声音，不必携带原视频、原录音或本软件。

完成制作后可以直接预演和导出，**不必先点「进入编辑」**。只有需要逐词调整时才进入编辑器。

## 三种模式怎么选

| 想怎么上课                 | 选择         |
| -------------------------- | ------------ |
| 软件先读，学生再跟读       | 配音跟读     |
| 教师先示范，学生再跟读     | 文字领读     |
| 没有示范，学生直接跟拍齐读 | 学生自主齐读 |

自主齐读先用默认的「每轮 4 拍、每次 1 拍」，即每轮提示读 4 次。长词或短语可以设为每次 2 拍，即每轮读 2 次；不是 2 拍换一个词。

## 换成自己的词表

在第 2 步粘贴自己的内容。建议连同表头一起复制下面的格式，再替换词语：

```text
英文	释义
achievement	成就
make a difference	产生影响
```

两列之间是 Tab 制表符，输入框中按 Tab 可以插入。不要用一串空格代替。也可以点「导入文件」选择表格；列用途不确定时，先确认「英文」和「释义」等用途，再点「下一步：校对内容」。词性、单元、重点等额外列可以保留，不要为了继续而随意忽略。

## 上课时只记这几个操作

新建词条默认一轮。开始前可点右上「课堂设置 → 练习安排」。选择一个词，填写 1～8 轮即可；只有一个词时直接填写。多个词想统一调整，选实际需要的范围、填轮数，最后一起点底部「完成设置」。手动和锁定轮数会保留。写错可恢复当前值，应用后可撤销。设置旁的问号可悬浮、聚焦或点击查看解释。

学生自主齐读还可在这里调整「每轮总拍数」和「每次朗读占用拍数」。例如 4 拍、每次 1 拍就是读 4 次；4 拍、每次 2 拍就是读 2 次，仍有完整 4 拍。舞台词块内的数字显示实际拍位，不是一块只有一拍。想连续换词，在「节奏与推进」把「词间间隔」设为 0；单词课没有词间间隔，无需显示该项。

在「练习安排」选择要调整的词，直接改轮数、每轮总拍数和每次朗读占拍；要统一设置，就在另一侧选择范围并直接填写目标，不必先勾选。显示「各词不同」表示目前没有统一目标；未编辑的字段会保留各词安排，点该项「还原」可取消本项统一调整。

临时管理词语：左侧搜索选词，中间改「英文／短语」「教学释义」与练习参数；点「新增词语」可加词，详情右上角可上移、下移或删除（均限本组且保留锁定位置），删除后可撤销。齐读要每词读四次，可用「此词四拍读四次」；要全部统一，可在右侧设范围、勾选是否包含手动值，再点「范围内四拍读四次」。锁定值始终保留，界面会显示实际影响。所有改动最后只点底部「完成设置」。

仅修改文字／轮拍时，课中当前词与重读保持原样，下一词或重玩使用新安排；新增、删除、排序后完成会返回开始页，按新词表从头开始。配音跟读换英文或新增无配音词会阻止完成，可明确改为整课文字领读；原配音保留，需要制作新配音请回编辑器。只想取消某词文字修改，点「还原此词文字」。

上课中也能改轮数、齐读拍数和词间间隔：从下一词或重玩生效，当前词和重读仍按已开始的安排练习；最后一词的修改等重玩生效。点「完成设置」后，这些调整保存在当前浏览器，关闭重开仍可用；要把设置带到别的电脑，请在编辑器修改并重新导出。

调完只需点底部「完成设置」，轮数、节奏、画面和音量一起检查并本地保存。关闭重开、「回到开始页」和重玩会保留成功保存的设置。收起不会保存草稿；可以回设置继续，或点「放弃未完成输入」。音量填 0～100 的整数，错误不能保存。设置中可「恢复课件原始设置」，确认后清除本课本地记录。浏览器清理数据、换浏览器或移动离线文件可能无法沿用，请以打开后的提示为准。

顶部提示框会说明「设置已保存」「等待下一词」或具体错误。恢复成功、普通操作确认4秒自动收起；鼠标悬停或键盘聚焦时保留，移开后重新计时。异常恢复、错误及等待下一词的信息持续可查。关闭提示不取消已保存安排。红色错误请按提示修正或重试，不能靠关闭提示绕过检查。

- **空格**：暂停／继续。
- **左右方向键**：切换词语。
- **R**：重读当前词。
- **全屏**：开始页就能开启，投屏前先调整好窗口。
- **结束课堂**：上课时直接点底部按钮，无需打开设置；结束后可以重玩。
- 默认自动推进；选了逐词推进时，按画面提示继续下一词。

HTML 是上课用的。`.ecglesson` 是以后导入软件、继续编辑用的，两者用途不同。

## 卡住时怎么办

- **不知道下一步在哪**：校对区右上方找「确认内容，下一步」；制作完成后找「导出课堂文件」。小窗口可向下滚动，校对表也可单独滚动。
- **提示列用途不完整**：按列里的实际内容选择用途；有歧义时先确认，不需要重新粘贴。
- **提示音色不可用**：旧课可能保存了这台电脑没有的系统音色。在「声音、口号与材料设置」中选择名称带「内置」的对应语言音色，再制作。已导入录音不要随意替换。
- **听不到声音**：有「测试声音」按钮时，先试听，再检查软件音量、电脑音量和教室音箱。若显示“本课按画面节奏练习”，说明没有启用声部；需要声音请回编辑器启用。文字领读／自主齐读本来就没有单词示范配音。
- **想用自己的伴奏**：在编辑器或「资源与设置 → 音乐与口号」导入音频／视频，再在课件中选择并启用。普通伴奏直接使用即可；初次使用不必调整音乐对拍或变速。

最后一次修改后，请重新导出，并打开新文件检查。不要把旧 HTML 当成新版本带到课堂。
