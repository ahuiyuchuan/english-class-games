# 课堂设置校验与布局

作者：ahui。产品版本保持 1.0.0。

## 复现与根因

现有离线文字领读示例：课堂设置 → 节拍音量百分比输入 201 → 出现范围提示 → 仍可完成设置并关闭。输入框只阻止非法值进入混音器，完成及播放入口却只检查逐词轮数；未应用的 BPM 也会被略过。双列长卡片、重复说明和未适配主题的滚动条增加了查找成本。

## 本轮行为约定（先于实现）

- 音量为 0～100 的整数百分比，节奏为 50～180 的整数 BPM，轮数为 1～8 的整数。空白、小数及越界保留原输入、就近显示原因，不静默夹取，不用旧值冒充新设置已完成。
- 只有本课启用的声部参与音量校验。合法音量只预览于试听，完成设置时统一应用于课堂；拖动对应滑条是明确的新输入，会更新数字并解除该字段错误。
- BPM 通过底部“完成设置”统一提交和正式编排校验；与已应用安排不同的输入属于待保存草稿。编排失败保留输入及旧编排，不允许完成。对拍课堂继续禁止独立修改 BPM。
- 批量轮数默认建议不自动应用；教师编辑数值或范围后，若实际会改变条目，由底部完成设置统一应用，或明确放弃。非法批量值同样阻止完成。草稿与范围在收起后保留，锁定／手动保护、实际影响预览和撤销不变。
- 即使未编辑默认批量建议，编辑后若正式编排拒绝（例如不循环的对拍音乐不足以覆盖增加后的轮数），也必须转为待处理。具体失败原因随草稿保留，收起重开不退化成错误的数字范围提示。放弃草稿清除对应错误显示，下一次输入不沿用上一项失败原因；原有效安排保持可运行。
- 非法设置阻止完成及新试听；待保存的合法草稿可统一完成，未完成变更阻止开始、继续、切词和重读，包括键盘快捷键。停止正在进行的试听始终可用。Esc／收起仍可退出面板，但不代表完成，课堂明确提示打开设置处理。
- 面板底部显示问题数量、定位第一个问题及“放弃未完成输入”。放弃只恢复尚未应用的草稿，保留已经应用的音量、轮数和其他设置；不等于恢复整课默认值。主动结束也放弃草稿。重玩保留已应用的会话安排；回到开始页恢复本课最后成功保存的本地设置。
- “完成设置”核对全部适用设置：每词轮数、已应用 BPM、推进、整课循环、继续前准备两拍、展示方式、释义、舞台特效、前后词预告，以及已启用的示范／口号、节拍、音乐音量。收起重开和重玩保留本次选择；运行中轮数／节奏沿用原定生效边界。完成时新增浏览器本地持久保存，关闭重开和“回到开始页”恢复最后成功保存的设置；不改原课件。存储、统一完成及恢复原值规则见 [15 · 本地保存与统一完成](15-课堂设置本地保存与统一完成.md)。
- 设置按轮数、节奏、画面、声音组织，提供直接定位入口、统一标题与紧凑字段布局；采用现有颜色／间距／按钮／说明组件。标题与底部操作固定，字段区域独立滚动，错误与具体输入关联，键盘焦点完整可见。避免大块等高空白与无意义装饰；不改游戏舞台和拍位词槽。

## 验收、兼容与回滚

记录原始 201 缺陷证据；回归所有数值边界、未应用 BPM、编排失败、批量草稿、收起重开、恢复、结束和重玩。实际浏览器检查三种模式、三个代表尺寸、焦点、帮助、错误定位和离线正向流程。执行类型／静态／单元／浏览器／便携构建及 Windows 打包，结果存入 `validation/settings-validation-review/`。

课堂设置规则不改变教学协议，旧课件无需迁移。桌面与新导出的HTML共用组件；旧HTML需重新导出才能获得当前修复。仅维护最新本地交付，构建与许可见[发版规范](21-1.0.0发版与仓库规范.md)和[对应源码](22-许可证与对应源码.md)。
