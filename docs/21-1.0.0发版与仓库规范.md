# 1.0.0 构建与发布规范

作者：ahui。产品版本1.0.0，主许可GPL-3.0-only。

官方仓库为 https://github.com/ahuiyuchuan/english-class-games，主分支main，正式标签v1.0.0，Release标题“English Class Games v1.0.0”。使用用户指定的完整简体中文提交消息，仓库以一个完整初始化commit交付。发布前核验仓库权限、远端分支、精确标签及同名Release，固定完整commit SHA；同名标签指向不同commit时停止，不自动覆盖。

发布操作遵循github-release-publish技能。Annotated Tag注释仅为“English Class Games v1.0.0”；Release正文统一按简介、重点功能、快速开始、下载说明、数据说明、项目信息、界面预览组织，具体内容来自本项目，不复制其他产品的功能或许可。现有CI是独立代码检查，不是该技能要求的发布步骤或门槛；实际发布仍逐项核验Tag、草稿、附件和正式版状态。

先推送明确的main和annotated标签，再建立正式版草稿，上传安装器、示例与可编辑包、完整对应源码、开发资源归档和SHA256清单。逐项核对服务端名称、数量、状态、大小及digest后公开并设为Latest。安装只需一个x64-setup.exe，其他附件按用途下载；不把源码或开发资源当作安装前置条件。CI在Release发布、PR或手动触发后验证代码，不自动发布；构建资源从本次固定版本Release获取后按release-resources.json核验，课堂运行没有下载依赖。

公开版内置BGM由scripts/build-builtin-music.mjs确定性合成，音频按CC0-1.0提供，原视频音乐不进入仓库、安装器、示例或源码。生成脚本是自有GPL-3.0-only代码，音乐本身单独标识；不改变教师素材许可。关于页恢复固定GitHub仓库／问题／发行入口及手动更新，只有点击检查才读取公开正式版信息，不传教学数据、不自动下载安装；离页取消请求，失败可重试，404不称最新版。

首发仅单词节拍三种模式，主要验收1920×1080。许可调整不改变教学、数据、运行协议和资料库。对应源码的范围、原许可边界、GPL第6条方案见[许可证与对应源码](22-许可证与对应源码.md)。

交付前检查格式、静态、类型、单元、原生、真实浏览器、离线HTML和构建。安装包包含许可、第三方声明及精确源码获取说明；完整桌面源码在同版发行页提供独立Source.zip，公开前核对可访问性与摘要。物理介质交付同时携带源码ZIP，HTML仍内嵌可离线下载的播放器源码；可编辑包区分软件与素材。安装器从校验过的运行资源暂存打包，不重复收录配音构建源码和播放器源码ZIP。按源码／运行核心／产物分别记录SHA256，检查同版本对应关系。不得用压缩JS、source map或无法访问的私有链接冒充完整源码。

只保留最新本地交付；修改已生成文件必须从模板或构建脚本重新生成。交付目录不得包含教师数据库、密钥、旧安装包及过期验收说明。未签名、未实测的安装／升级、设备输出和最低系统环境分别记录，不伪造通过。当前实际命令、结果和限制见[验收记录](release-notes/validation-1.0.0.md)。
