# 01 · AI 赋能与教学规则

> V1.0 最终设计基线 · 作者：ahui · 2026-10-20 · [返回总览](english-class-games-详细设计.md)

## 1. AI 赋能的产品方式

**教师确认教学材料、重点与练习预设，系统完成可解释的整理、推荐、编排、配音和成品检查，教师拥有最终决定权。** 助手采用步骤式任务界面，不采用聊天机器人界面。

| 能力 | 输入 | 本地方法 | 可见结果与教师操作 |
| --- | --- | --- | --- |
| 智能整理 | 词表、表格、阅读文本 | 文本解析、短语匹配、词形索引、重复检测 | 候选词、来源位置、缺失项；选择、修订、忽略 |
| 词义辅助 | 英文、教师释义 | 教师常用词库优先，再查高中词库 | 候选义项、词性与来源；教师选择教学义项，即本课采用的具体词义 |
| 练习建议 | 词数、重点、预设、目标时长 | 参数表与规则匹配 | 预设参数与时间调整建议；说明重点加练、短语留白和调整依据 |
| 智能编排 | 已确认词条、真实声音时长 | 整拍计算、段落与口号插入规则 | 可编辑的播放安排与实际编排时长 |
| 一键配音 | 文本、语言、音色、语速 | 内置离线神经配音／Windows 系统音色与缓存复用 | 单词和口号音频、逐项试听、失败重做 |
| 一键改编 | 当前版本或课件副本、新材料、锁定项 | 固定规则、模板选择、依赖比较 | 保留项与修改前后差异；应用、放弃或撤销 |
| 智能检查 | 当前版本、声音模式、所需素材 | 字段、依赖、时长、素材与文件校验 | 问题清单、具体位置、修复入口与导出结果 |

不展示模拟思考、模型置信度、虚构的语义理解或学习诊断。推荐依据必须来自已触发的规则；不把模板选择称为自由创作，不把节拍高亮称为语音识别。

智能能力通过游戏化界面呈现：工作台的全息编排核心说明“材料 → 本地规则与声音 → 课堂成品”，制作页展示实际步骤与成果，编辑器把建议连接到具体字段，课堂按已确认编排自动运行。装置、轨道、星尘和光束是视觉表达；任务进度只使用真实阶段和数量，课堂进度只使用实际完成条目。配色、动作和交互统一按 [视觉规范](02-页面交互与视觉规范.md)执行，不将装饰当成额外的智能能力。

词库匹配、词形索引和已有标签只能提供候选，不表示系统理解了文章语境、判断了学生水平或完成了多义词消歧。默认选词顺序、教学义项和练习强度均保留教师决定权。

智能操作通过“整理材料、接受候选、一键制作、检查建议、换一版、更新声音”等明确动作触发。结果就近显示依据、影响和下一动作；未命中词库、没有可变项或检查未通过时如实说明。教师确认只接受本次展示的范围，不能被解释为允许以后自动覆盖。

首次成稿与修改已有内容采用不同的确认边界，保证“一键制作”能够连续完成，又保护教师已有编辑。

| 场景 | 自动完成的范围 | 需要教师决定的内容 |
| --- | --- | --- |
| 整理材料 | 解析、匹配、分组、标记疑似重复和缺失 | 选取阅读候选、接受教学义项、排除重复或错误行 |
| 首次一键制作 | 在已确认材料和设置内完成分段、默认参数、模板口号、配音与检查，不逐项弹窗 | 制作前确认本课范围与设置；失败后选择修复或调整模式 |
| 编辑与改编 | 检测受影响项、复用匹配声音、计算建议及差异 | 应用建议、覆盖手动值、换一版、更新声音；未确认不替换现有内容 |
| 检查与携带 | 课堂 HTML 校验运行版本并打包启用资源；可编辑包独立校验草稿、已准备版及其全部素材 | 选择保存位置与覆盖范围，分别查看结果，打开实际课堂文件测试声音 |

平台共用材料候选、来源、声音任务和交付检查，各游戏提供自己的建议规则与课堂呈现。后续游戏接入同一智能制作流程，不要求采用节拍、轮数或单词节拍的结果形式；首版不提前实现第二个游戏。

## 2. 内容来源与校对

### 2.1 来源和优先级

采用 **教师自有内容为主、本地高中词库辅助、教师确认后成稿** 的方式。

| 来源 | 行为 |
| --- | --- |
| 粘贴词表、导入表格 | 保留原文、顺序、词义、单元、重点；可保存为材料集，不自动改变教学范围 |
| 粘贴阅读文本 | 提取候选并标明原文位置；教师勾选后才进入课件 |
| 基础高中词库 | 随安装包离线提供，包含参考释文、明确标记的已校对教学义项、词形和短语；主题只匹配已有标签 |
| 教师常用词库 | 教师主动保存的修订、重点和标签；不由一次课堂操作自动积累“学习画像” |

同一字段采用：**当前课件内教师确认值 → 教师常用词库 → 基础词库候选**。词库更新不覆盖教师内容；课件保存教学内容副本，不实时跟随词库变化。

此顺序决定候选优先级，不代表自动接受。原材料已有的教师释义直接保留，空释义只展示候选；即使仅有一个义项，也经教师点击接受后才写入。阅读候选默认不勾选，可按组全选后排除；不默认接受第一义项，未选择义项仍可制作仅英文练习。

教学材料分为“材料集”和“常用词库”：材料集保存一次导入 / 粘贴的原文及确认词条，可选词用于智能制作；常用词库保存教师主动选择复用的词义、重点和标签。材料或课件编辑后，可将所选词条保存到常用词库，先预览新增与冲突；教学字段完全相同不重复保存，仅重点 / 标签不同时可选择更新或保留，已有不同义项时由教师选择新增义项、更新指定项或跳过。导入条目改英文后，原先不再匹配的指定更新目标失效，按新英文重新选择；直接编辑既有常用词仍可更新该条目。修改、删除材料或常用词不追改已有课件。

保存原文与规范化文本，匹配忽略首尾空白、合并多余空格，检索时可忽略大小写，展示保留专有名词、缩写、连字符和撇号。阅读提取先匹配词库中最长的连续短语，再匹配单词；短语中相邻词之间只允许空格或 Tab，不跨标点或换行匹配，词内连字符和撇号保留。内部单词收进短语的展开层，不随短语联动勾选，教师可独立添加。所有候选初始均不勾选。词形索引仅提示原形与对应义项，不悄悄替换原文。

课件条目的“单词 / 短语”标记用于时间安排：词库明确标为短语，或英文包含至少两个以空格分隔的词时默认标为短语；连字符连接的单个词不据此拆开。教师可在练习属性中覆盖该标记，保留其手动来源。阅读词表的分组只是候选展示，加入课件默认恢复原文首次出现顺序；教师选择保留重复位置时才加入多次。

阅读候选按“教师重点命中 → 高中词库命中 → 其他原词”分组，组内按原文首次出现顺序；常见功能词折叠展示，已命中教师重点的词保持展开。重复出现显示次数与位置，不按频次声称教学重要性。未收录词允许手工加入，多义词保留候选；不能凭空补出释义。

功能词按随词库发布的版本化清单匹配，V1 清单为 `a、an、the、and、or、but、if、as、at、by、for、from、in、of、on、to、with、am、is、are、was、were、be、been、being`。该清单只决定候选是否折叠，不排除词条、不判断教学价值；教师可展开选择，重点命中优先保持展开。清单版本随整理结果记录，保证相同输入与版本得到相同候选分组。

候选义项可完整展开，接受后可改写为本课教学释义；超过 200 字符须修订，不静默截断。材料原文位置与词库名称 / 版本分别保留，教师改写标为“教师修订”，仍可查看原候选来源。词库候选的校对状态与本课是否接受分别保存；接受、改写或保存常用词不把未校对参考变成已校对义项，历史记录缺少校对信息时显示“未记录校对状态”。

基础词库从 ECDICT 的 `gk` 标签筛选，再进行教学校对；筛选完成不等于校对完成。分发清单记录来源提交、加工版本、单词 / 短语 / 独立义项数量、词形索引、校对范围与许可。未经拆分校对的多义释文只能作完整参考，不能按“一条词库记录”冒充一个独立教学义项。

词表 / 表格导入的疑似重复按“去首尾空白、合并重复空格、忽略大小写的英文”分组提示，保留各行原文、义项和位置。默认保留全部，只有教师明确排除才减少条数；不同义项、跨段重复及 `US` / `us` 不因检索匹配而被合并或改写。阅读文本仍按上述候选与出现位置规则处理。

### 2.2 导入、限制与错误

模板字段为英文、中文释义、词性、单元、标签、重点标记；单元与标签是独立字段。英文必填，其他可空，重点填写“是 / 否”，空值按“否”。英文每条 1～120 字符，释义不超过 200 字符，词性不超过 40 字符，单元不超过 80 字符，课件名 1～80 字符；去除首尾空白后校验，字符按 Unicode 码点计数。Tab、换行可作规定的导入分隔符；引号内字段换行整理为空格，原始内容仍保留，拒绝字段内其他控制字符。

标签最多 10 个，每个 1～24 字符；以中英文逗号分隔，去除各项首尾空白、忽略空项，完全相同的标签去重并保留首次顺序。逗号只作分隔符；超限保留输入并提示修正，不截短标签。若原表只有一列“单元 / 标签”，由教师在列映射中选定用途，不按内容猜测；导入校对、材料详情和编辑器使用相同规则。

| 输入 | 规格与边界 |
| --- | --- |
| XLSX | 最大 20 MB，解压总量最多 200 MB、ZIP 内文件条目最多 2,000 项；选择工作表和列用途；无需安装 Excel，不执行公式或外部链接，缺少公式缓存结果则提示改为普通文本 |
| CSV / TXT | 最大 5 MB；UTF-8 默认，可切换 GB18030 并预览；CSV 支持引号内逗号和换行 |
| 文本粘贴 | 每次最多 20,000 字符；词表按行，一行一个单词或短语；中英文分列可使用 Tab |
| 单词节拍词表 | 每课 1～100 条；同一词在不同段落可重复，每个出现位置有独立条目标识 |

材料集最多 2,000 条，不套用单课 100 条的上限；用于制作时再选择本课范围。超过对应上限时保留原输入并要求缩减 / 拆分，不静默截取前若干条。重新粘贴或切换输入来源后清除旧文件的编码、工作表与列映射，按新来源重新预览。

流程：选择 / 粘贴 → 解析预览 → 指出重复、缺失和格式错误 → 确认追加 / 替换 → 写入草稿。预览提供“首行是表头”开关，仅首行完整匹配支持的列名时默认开启；无表头时保留第一行，不因 `homework` 等英文包含列名片段而跳过。教师可调整开关和列用途，随后重新预览。

单列无表头输入默认作为英文。无表头多列输入须在预览中逐列确认用途，不按列数猜测单元、标签或重点；每列可映射为一个教学字段或明确选择“忽略”。英文须且只能映射一列，其他教学字段至多各一列；遗漏映射或重复映射时不能确认导入，保留原内容并定位到对应列。

读取 / 解析新来源期间禁用确认，旧预览不得提交；切换文件、编码、工作表、列映射或重新粘贴后，只接纳最新一次读取结果，迟到结果不回写。错误定位到行和字段，可修正或明确排除错误行后导入有效行；替换先列出受影响条目和段落，整次操作可撤销。词义缺失为提醒，不阻塞仅英文练习；英文为空、条目超限、非法数值必须修正。

已报错字段修正后即时重新校验，正确后解除阻塞。批量接受词义只作用于当前已选、释义为空且恰有一个可接受候选的行，先显示实际数量；排除行不计数、不修改，已有教师释义不覆盖。存在多义项的行仍须逐项选择，不能批量代选第一义项。

可批量接受的候选必须是一个独立、非空且符合字段限制的教学义项；一条记录含多义释文、未完成校对或超出长度限制时，不计入可批量接受数量，教师仍可展开参考并手动填写。

不支持 PDF / 图片 OCR、教材全文抓取、联网搜词、任意自然语言指令生成。用户文本始终作为教学数据，不执行其中的指令、脚本或路径。

## 3. 智能制作流程

### 3.1 三步完成

1. **内容校对**：导入并确认词条、教学义项和重点；候选补全在此统一确认，避免每词弹窗。
2. **活动编排**：选择游戏、练习预设和目标时长，查看段落、口号与推荐理由。首版游戏固定为单词节拍，其他参数可展开修改。
3. **声音制作与检查**：检查实际音色，制作或复用声音，按真实时长排布，显示结果与问题；进入编辑、试听开场或导出。

目标时长默认 5 分钟，可设 1～30 分钟，支持小数，例如 7.5 分钟，指编排本身的参考目标，不含教师等待、暂停和临时重读；不能据此承诺整堂活动恰好结束。首次使用默认常规巩固、配音跟读、节奏方块、自动推进；后续沿用教师主动保存的新课默认值，页面显示本次实际参数。可保存项为预设、目标时长、声音模式、展示模式、课堂推进模式及各语言音色 / 语速；仅点击“保存新课默认”才写入，本课修改不自动回写，也不批改已有课件。默认自动推进仅用于没有已保存偏好的新课，已有课件及主动保存的逐词 / 居中偏好按原值使用，不隐式迁移。新课默认名称“单词节拍_YYYY-MM-DD”，教师可在编排页或编辑器修改。

只有计时所需的示范或口号声音未就绪时，才显示“声音准备后计算完整时长”；准备完成后计算实际安排与时间建议。文字领读按教师示范拍数计时，关闭全部口号时无需任何配音即可算出完整时长；背景音乐不改变编排时长。编辑时按当前修订刷新受影响建议的有效状态；需要重算时由教师点击重新检查，不会自动应用建议、合成声音或覆盖其他字段。

每条建议保留本次检查所用的内容、参数与锁定状态。相关值改变时标“需重新检查”，禁用旧建议的应用；无关编辑不撤掉仍有效的建议。忽略只对本次检查的相关值有效，改变后可再次提示。应用前再次核对并显示真实差异，应用后复查，已解决的问题不继续提示；底层保存方式见[智能处理链](04-技术架构与数据规范.md#2-本地智能处理链)。

### 3.2 单词节拍预设

新建课件及新增条目初始均为一轮，普通词与重点词相同；三种模式一致。向导帮助与当前安排摘要都必须说明一轮初始值，不再暗示自主齐读新建即沿用预设多轮。下表轮数只在教师主动应用对应教学预设、恢复预设或接受建议时生效，已有课件及手动／锁定值不因新默认而改变。

配音跟读与文字领读的一轮为“示范一次 + 一次跟读空间”；自主齐读的一轮直接按设定总拍数朗读，没有示范阶段。BPM 表示每分钟拍数，数值越大节奏越快；`M` 为示范占用拍数，计算归属[课堂运行规范](03-课堂运行与便携交付.md#1-节奏与时间计算)。

| 预设 | BPM | 普通 / 重点轮数 | 单词跟读拍数 | 短语跟读拍数 |
| --- | --- | --- | --- | --- |
| 常规巩固 | 100 | 2 / 3 | M | M + 1 |
| 重点强化 | 90 | 3 / 4 | M + 1 | M + 2 |
| 限时复习 | 110 | 1 / 2 | M | M + 1 |

通用范围：BPM 可调 50～180，轮数 1～8，跟读拍数 1～32；整课开始准备 4 拍，后续段落开始准备 2 拍。两种示范／跟读模式默认词间转场 1 拍；自主齐读默认词间间隔 0 拍，每轮 4 拍、每次朗读占 1 拍，详见[自主齐读规则](07-学生自主齐读.md)。按原始顺序每 10 条形成一段，末段保留余数；不为了强化自动复制词条或重排重点词。教师修改段落后保留其组织。

参数来源保留为“预设 / 教师手动”。切换预设前显示差异，只更新未锁定、未手动指定的字段；切换重点标记只改变由预设管理的轮数。修改单词 / 短语标记时，未锁定且仍由预设管理的文字示范拍数随类型变为 2 / 3 拍，手动值和锁定值保持；批量修改遵循同一规则。恢复预设须明确选择相应字段，文字示范拍数按当前类型计算，不清空其他编辑。

预设卡展示实际依据，例如“重点词多练一轮”“短语额外留出跟读空间”；目标时长只用于后续时间建议，不据此推断学生能力。锁定预设跟读时保留公式及所属预设，声音变长或 BPM 改变后仍按新 M 计算；需要固定留白时，教师先切为手动拍数再锁定。

### 3.3 时间建议与优先级

编排首先保证英文声音完整，其次保留教师手动值和锁定项，再使用预设，最后使用通用默认。**锁定限制智能修改，教师仍可直接编辑。** 修改英文后旧音频必须失效，即使声音已锁定也不能继续冒充对应配音；显示冲突并要求更新或导入新录音。

实际编排时长超出目标时，依次生成建议：关闭仍由模板 / 预设管理、未手改且未锁定的可选转场口号；普通词每次减少一轮至 1；重点词每次减少一轮至 1。每轮调整按原始顺序遍历，只纳入非手动、非锁定项，达到目标即可停止。转场口号的文本或启用开关任一已手改，均不建议自动关闭；开场和收尾默认保留。

仍超时且目标不足 30 分钟时，可建议延长目标，建议值不超过 30 分钟；延长后仍超时须显示剩余差额，提示调整允许修改的参数，或进入「比较练习目标／预览拆为多课」查看整课分组。拆课预览列出每课内容与真实时长，教师确认后创建独立副本，保留原课及全部词条，不宣称单条仍超时的分组已经达标。目标已达上限时不再提供延长动作。

建议展示具体条目、原值、新值、节省时间及调整后总时长，教师确认后才应用。时长不足时显示实际时长，不自动加词、补轮或填充空白。提高 BPM 不一定缩短整课时间，必须重新按整拍计算，不将其当作固定的“省时”手段。

确认应用时间建议后，修改字段按“教师手动”保存，并保留所用规则与差异记录；重新打开或切预设不自动恢复。仅展示 / 忽略不改变参数来源；撤销恢复原值及来源，主动恢复所选字段的预设时再交回预设管理。

### 3.4 口号与声音

内置高中课堂口号模板包含编号、版本、语言、用途和允许占位符，开场、收尾、转场至少各 3 条已校对模板。默认开场、收尾各一句，转场口号关闭；教师启用转场后只在段落之间插入一句，鼓励文案可作为转场模板选择，不增加随机插话功能。只在轮次外插入，不覆盖示范和学生跟读；内容简短，不使用幼儿化表扬或未经依据的学习评价。教师修改的是本课口号，不反向改写内置模板；文本与启用开关分别记录是否由教师手改。

开场例：“准备好，跟着节奏开口。”收尾例：“练习完成，回顾今天的重点词。”首版占位符仅允许 `{{lessonName}}` 和 `{{wordCount}}`，从已确认课件取值；缺值、未知占位符或超过 60 字符的口号不得生成声音，定位到该口号修正。无其他匹配模板时保留原句并说明无替代项。

60 字符按占位符展开后的最终口号计算，仍按 Unicode 码点计数；属性区同时提供原文本和展开预览。课件名或词数变化后重新检查长度与声音匹配；超限保留输入，不能自动缩写课件名、截短口号或继续使用旧声音。

英文示范与中文 / 英文口号分别按语言选择音色；新课默认选择内置离线中英音色，教师仍须试听；已保存的显式音色不自动替换，不假定系统一定安装。语速默认 1.0 倍，可调 0.75～1.25 倍。音色不支持所需语言时阻止该项制作；可选择对应语言的内置音色、其他实际可用系统音色、导入录音，或明确选择文字领读。已准备的声音可直接携带和复用，不因换电脑悄悄换音色。

制作前按实际声音需求检查，不以“本机没有某音色”直接阻止已有课件使用。

| 当前情况 | 处理与结果 |
| --- | --- |
| 已有与文本和设置匹配的有效声音 | 直接复用；携带后的播放不要求目标电脑安装原音色 |
| 需要新声音且对应音色可用 | 继续制作；单项失败就近重试，保留成功项 |
| 需要新声音但音色不可用 | 列出受影响词条 / 口号；选择可用音色或导入录音后重新检查，不冒充成功 |
| 教师明确改用文字领读 | 停用英文示范；逐项处理仍启用的缺损口号，选择修复、导入录音或关闭；列出仍未解决项，全部满足后才可上课 |

系统配音不自动判断 `record`、`read` 等同形异音词的教学读音，也不保证缩写的朗读方式符合本课要求。教师须试听；需指定读音时可导入对应录音。修改词性或教学释义不代表系统已纠正发音，也不自动改写英文。

系统配音采用“条目明确覆盖值 → 本课默认值”的优先级；批量修改只写入勾选条目的覆盖值。音色和语速逐字段继承，修改其一不固定另一项；恢复使用本课默认须明确操作，之后本课默认变化才影响该项。手工录音不参与此继承。

文字领读只关闭英文示范；已启用的口号仍需对应声音。缺口号音色时，可导入口号录音或明确关闭受影响口号，界面列出声音模式变化及仍未解决项；全部启用资源满足后才可运行或导出课堂 HTML。

### 3.5 改编、结果与复现

“换一版”默认只替换未锁定、未由教师手改的模板口号；教师可额外开启“调整词序”“恢复预设参数”或“允许替换手改口号”。调整词序只在当前段落内排列，锁定位置保持不动；恢复预设仍保护手动值，覆盖手动值需另行勾选“允许恢复手动参数”。任何授权均不解除锁定；先展示实际差异，再整体应用，可一次撤销。

每次打开改编，额外范围和两项手动覆盖授权均默认关闭，仅作用于本次操作。“允许恢复手动参数”仅在“恢复预设参数”开启时可用；关闭父项同时清除该授权，重新开启仍须主动勾选。关闭、放弃或完成改编后不沿用授权；修改范围后原预览不能直接应用，须重新预览。

保存本次制作内容、规则 / 模板版本、声音时长、参数来源与口号 / 词序选择。同一版本重复打开、保存或导出保持相同编排；只有主动“换一版”才重新选择，具体复现方法由[智能处理链](04-技术架构与数据规范.md#2-本地智能处理链)定义。候选有替代项时优先排除当前口号；没有可变项或没有实际差异时直接说明，不制造无意义的新版本。

建议记录至少包含作用对象、规则编号、理由、修改前后值和是否应用。例如在 M = 2、常规巩固时：“take part in 标为短语，按 M + 1 留白，跟读由 2 拍增加为 3 拍。”结果摘要显示整理条数、确认补全项、重点词、段落、实际时长和声音准备数量，不显示虚构的“AI 得分”。

整理条数按保留的条目位置计，轮数和重读不增加条数。确认补全只计“原先为空、教师接受候选后当前仍非空”的释义 / 词性字段，每个条目的每个字段最多计一次；已有教师值、未接受候选和重复接受不累加，清空后不计，撤销恢复对应计数。保存和复制保留接受记录；缺少记录的历史数据不凭现有非空值推算补全成果。

声音数量按本次任务固定输入的唯一声音需求计：本次实际合成成功计“新制作”，未重新合成而使用已准备声音或有效缓存计“复用”，尚未成功的需求计“未完成”；三类之和等于需求总数，同一声音重复使用只计一次，缓存于任务启动后命中也计复用。失败属于未完成的子集，另列供重试。各处摘要使用同一口径，不能把推荐候选、缓存命中或未完成任务显示成新生成成果。

### 3.6 复制课件与换课复用

“复制并改编”先确认副本名称及“沿用原内容 / 替换材料”，确认后创建独立课件；确认前取消不创建。副本保留设置、手动值、锁定和可复用声音，原课件保持原内容。选择替换材料时，再展示保留的课级展示、节奏、声音、预设和目标时长，以及将替换的词条、段落与口号变化；创建后取消替换，保留沿用原内容的副本。

确认替换后，新词条取得独立标识，按所选预设编排；不把旧词条的手动轮数、锁定或段落安排套给新词。保留课级设置与锁定，以及原口号文本、启用开关和各自来源；新段落按所保留的转场口号设置编排。

仍匹配文本和声音设置的音频可复用，其余更新；含课件名或词数的口号重新展开占位符，仅使实际文本改变的声音失效，锁定也不能保留不匹配的声音。替换口号模板仍走“换一版”的差异确认。未确认前不改变内容，整次替换可撤销，完成运行检查后才可导出课堂 HTML。

## 4. 任务与失败边界

任务展示实际阶段和完成数量：整理材料 → 准备方案 → 制作 / 复用声音 → 按真实时长编排 → 完整检查；文字领读无声音需求时直接进入编排，不制造配音步骤。准备方案只确定设置、口号与声音需求，最终安排在声音就绪后计算；具体执行顺序见 [本地智能处理链](04-技术架构与数据规范.md#2-本地智能处理链)。未知总量时显示阶段，不编造百分比。同一课件相同输入不重复启动制作；可取消，已完成声音保留以供重试，不把半成品标为可上课。

缺词义为“可补充”提醒；声音未制作、过期、文件丢失与损坏按[界面状态规则](02-页面交互与视觉规范.md#33-状态与反馈)区分，问题清单提供定位和下一动作。制作时继续编辑形成新课件版本，结果只属于本次制作内容，不能覆盖新草稿；教师可查看原成果或重新制作当前版本。

任务独立保留制作所用的材料、设置与声音，删除源课件后仍可查看原成果，不自动恢复课件或合并到其他草稿；教师清除已结束的任务记录时才释放这份保留。

配音跟读要求全部示范和已启用口号准备完成；文字领读关闭示范，可保留已准备的口号、节拍与音乐。运行检查只要求当前模式启用的资源，不自动降级、不要求生成已关闭声音；课堂运行和 HTML 导出使用同一检查入口。可编辑包允许未完成草稿，独立检查当前草稿、存在时的已准备快照及全部引用素材，按[可编辑包规范](03-课堂运行与便携交付.md#5-可编辑包与换机)执行。
