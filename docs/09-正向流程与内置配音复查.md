# 正向流程与内置配音复查

作者：ahui。2026-10-21。产品版本 1.0.0；本文件先记录实施约定，实测结果另存于 `validation/usability-recheck/`。

## 已确认问题及处理顺序

1. 音乐导入组件以 Fragment 向 `row spread` 插入结果文本，使两个布局项变为三个。取消状态必须在组件自己的稳定容器内显示，不参与父标题栏分配；取消不使用失败色，说明没有新增音乐。编辑器和资源页共用修复。
2. 材料整理只建议无歧义双列；实际六列示例没有表头，所有用途为空，确认入口又在映射区上方。内置示例补充真实表头；通用解析对有依据的词性、单元、重点及中英列提供可确认候选，不能凭剩余位置猜标签或忽略列。歧义保留人工选择。映射区底部明确展示下一步、未完成数量和错误，确认后进入校对；校对主动作保持可达。
3. 配音只枚举系统音色，缺英语声音就无法完成默认制作。增加随安装包分发的真实离线神经配音，复用现有任务、缓存、语速、试听、素材引用及导出；Windows 声音仍可选。新课在没有教师指定音色时优先使用内置英语／中文音色；已有明确选择不静默替换。音色模型不是理解教学目标的大语言模型，不改变已有模型能力说明。

## 内置声音约束

采用 sherpa-onnx 1.13.8 Windows x64 CPU + MeloTTS 中英双语女声 FP32 模型。模型 MIT、推理核心 Apache-2.0；实际 C API 二进制链接 eSpeak NG，因此配音组合按GPL第3版分发，自有适配代码GPL-3.0-only，上游eSpeak保留GPL-3.0-or-later声明，安装包保留许可，同版本Source.zip独立附件提供对应源码和构建方法；物理介质同时携带源码。压缩包内 int8 文件实际为 Git LFS 指针，不作为模型分发。中英选项使用同一双语声线，教师仍须试听同形异音词及缩写。无需用户预装 Python、FFmpeg、语音包或模型服务。引擎和模型保存在只读安装资源中，以固定白名单音色 ID 调用；不执行用户提供的程序路径。

输入仍为每项最多 200 字符、语速 0.75～1.25；任务串行且支持取消。子进程使用结构化参数、隐藏窗口，单项 60 秒超时，产物最多 30 秒，输出 WAV 经原有真实解码和时长限制后才入库。取消、超时、失败均终止并等待子进程，清除本项临时文件；启动后的旧临时目录按已有恢复策略清理。原文不上传、不写入日志。缓存键区分模型／引擎版本，原系统音色缓存仍兼容。

## 交互与验收

追加布局复查：第一版验证截图中的大标题、英文眉题、AI 徽章、步骤条和说明横幅重复占高，且悬浮确认条覆盖原文，此版不作为验收结果。制作页改为紧凑任务标题＋步骤导航；阶段解释融入标题副文案。整理后将原文和列设置收起为可重新展开的来源区，内容校对成为主体。操作条采用正常文档流，不能悬浮遮住输入；校对表有独立、明确的滚动边界。短屏保留最少必需导航，把空间留给实际词条。浏览器运行限制在任务页可展开阅读；主确认动作在校对区顶部与来源入口同一操作行，短屏无需滚到末尾寻找下一步；底部只保留全选、清空和分页，避免重复数量与零值信息。CSS 使用任务页作用域，避免被全局页头规则覆盖。宽／窄截图必须同时看得到任务、内容与操作关系，不能只断言按钮存在。

从空资料状态走“示例／粘贴／文件 → 列用途 → 内容校对 → 练习安排 → 制作 → 预演 → 导出”，不由测试偷偷填入系统默认不提供的字段。记录操作数及缺失条件提示。有表头示例不再需要手动选择六列；无表头不确定列保留显式确认。换来源、编码、工作表及手工改列后，旧预览失效。

制作完成且无阻断问题时，“导出课堂文件”为主要操作，编辑为可选后续；有阻断问题时，主要操作改为进入编辑修复。这样简单课件可以从制作向导直接预演和导出，不强迫绕行编辑器。复查结束后提供使用实际按钮名称的快速上手手册。

取消音乐导入前后，按钮右边界及横向位置不变；消息不遮挡列表和按钮，键盘焦点回到入口。三种模式保留专属配置，学生自主齐读不要求示范声音。继续检查 4 拍读 4 次／读 2 次、32 拍窗口、暂停、重读、换词、完成及重玩；四个拍垫中的单词保持可见。

验证包括真实 Windows 音色试听和制作、缺系统英语音色仍可生成、取消及重试、中文／空格路径、课件包往返、离线 HTML 的内嵌音频，以及 720×480、911×480 和投屏大小的实际布局。无 .git，使用本轮修改前副本和 SHA-256 对照；旧交付保持原样，不提交或推送。新字段若无必要不增加；内置 voiceId 属于既有不透明音色字段，课堂导出只播放已生成声音，离线课堂不需要推理模型。回滚可安装旧交付，已保存 WAV 仍可播放，但旧版不能重新合成新的内置音色 ID。

静态复查发现原有音乐内置资源初始化函数位于 Rust 测试模块之后，触发 Clippy 的模块顺序错误。本轮仅将该函数移至测试模块之前，不改变导入、种子资源或数据库行为。打包前校验 resources/tts/manifest.json 的完整文件清单与哈希，缺件、变化或占位模型均拒绝构建。
向导预演的返回入口显示“返回制作”，编辑器预演仍显示“返回编辑”；名称对应真实返回位置。
