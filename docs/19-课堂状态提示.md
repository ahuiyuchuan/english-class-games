# 课堂状态提示

作者：ahui。2026-10-22。产品版本1.0.0。

## 目的与布局

复用课堂现有单一反馈槽、Phosphor图标和共享语义颜色，不引入Ant Design或另一套通知服务。借鉴Alert的图标、标题、正文和关闭结构，保持深蓝底、长短角及青色操作边缘。课堂提示置于顶部居中浮层，不再作为横贯底部的布局子项挤压舞台；设置打开时移入弹窗，内外互斥，不能重复播报。主要验收设备1920×1080，其余尺寸保留基本兼容。

普通提示不抢焦点，使用status；错误使用alert。图标与标题共同表达状态，不能只变色。外围浮层不拦截鼠标；提示和明确的关闭按钮才响应。入场只用短促透明度／位移动画，减少动态偏好停用装饰动画，不影响文字。

浮层按课堂场景避让：开场与结束靠近页顶，游玩时位于词序／阶段之下、中央英文之上，不能盖住词序。截图需等待短入场结束，录像保留真实出现过程；不能把动画第一帧透明误当作最终外观。

普通确认显示4秒自动收起。鼠标停在提示上或键盘焦点进入提示时暂停收起，移开后重新留出4秒阅读时间；不能因到期移除正在操作的关闭按钮，也不能因此永久滞留。主动关闭后焦点接续到设置的完成按钮，或课堂开始／播放／结束标题等当前场景主操作；自动收起及鼠标点击其他区域时不抢焦点。浮层不捕获Esc，不干扰原设置及帮助的关闭层级。

## 状态与生命周期

| 真实事件                                       | 提示与行为                                                                  |
| ---------------------------------------------- | --------------------------------------------------------------------------- |
| 已保存并立即应用、恢复原课、真实安装待生效安排 | 成功，可关闭，4秒后隐藏；同文案的新事件重新计时                             |
| 成功恢复本课本地设置                           | 普通信息，可关闭，4秒后隐藏；收起只移除提示，已恢复设置继续有效             |
| 放弃草稿、无声音可试听、试听结束、全屏不可用   | 普通信息，可关闭，4秒后隐藏；试听不假称已测试实体音箱，全屏失败仍可窗口上课 |
| 已保存但下一词／重玩生效                       | 信息，持续或手动关闭；关闭不能清除待生效时间轴，真正安装后才报告已生效      |
| 本地设置损坏／过期／无法读取、仅本次使用       | 警告，可手动关闭，持续说明降级原因与下一步，不套用普通确认的超时规则        |
| 有未完成草稿                                   | 持续警告，完成或放弃才消除；关闭普通消息不能绕过保护                        |
| 非法参数、配音失配                             | 持续错误，保留原输入、定位及放弃动作                                        |
| 保存失败、运行故障、声音初始化／试听失败       | 持续错误，不自动消失；保留重试或其他现有恢复动作                            |

运行故障优先于普通提示，设置中有合法草稿也必须可见；仅隐藏无关的旧成功信息。保存失败继续在设置中显示，不能被成功消息覆盖。恢复结果用明确内部状态区分“无记录／恢复成功／异常回退”，不靠匹配中文提示判断是否成功。自动隐藏定时器按消息对象绑定，替换、重置、关闭和卸载时清理，旧回调不得清除后来错误。鼠标／焦点监听随同清理，无轮询；逐拍渲染不重新计时。提示不决定拍位、保存结果或时间轴安装。

初始化／试听错误也适用上述合法草稿保护，不只是运行控制器的error状态。优先级为运行故障、非法设置、初始化／试听错误、合法待保存草稿、普通消息。参数非法时保留就近字段错误，修为合法后仍可见尚未重试的设备问题；不能仅保留卡片DOM却用警告正文替换原错误。错误恢复说明同时尊重未完成草稿保护。

## 兼容与验收

提示修复不改变课件或运行协议；后续词表管理已将独立本地设置升级v5，见[课堂词语管理](18-课堂临时词语调整.md)，不修改教学规则和音频架构。旧HTML需重新导出才获得新提示外观；按用户最后指示仅保留最新打包。回滚恢复本轮受保护源码并重新构建，不回写教师数据。

实测刷新恢复成功的出现与4秒收起、无记录无提示、异常恢复持续、普通试听等同类提示、悬停／聚焦保留及移开后收起、成功关闭／超时、连续同文案、错误持久、合法草稿不吞运行错误、待生效关闭后仍正确跨词、设置内外唯一语义区、全屏、减少动态、卸载清理。以1920×1080真实断网HTML截图和运行录像检查舞台、顶部工具及完成按钮可达，其他尺寸仅补基本兼容。记录实际执行结果，不能把单元模拟音频当成实体声音测试。
