# 02 · 页面交互与视觉规范

> V1.0 最终设计基线 · 作者：ahui · 2026-10-20 · [返回总览](english-class-games-详细设计.md)

## 1. 视觉方向与公共布局

主要运行设备为1920×1080，按用户2026-10-22补充说明，以该设备的课堂可读性、设置可达性及完整流程为主验收。其他尺寸保留基本兼容和关键操作，不为小窗口单独扩大布局改造；已有兼容回归继续保留。

课堂反馈采用主题Alert结构：图标、短标题、正文及适用的关闭按钮，顶部居中浮层不挤压舞台；设置打开时在弹窗内互斥显示。成功、待生效、警告和错误按真实事件分类，关键故障不能被合法草稿隐藏。具体生命周期及恢复约束见[课堂状态提示](19-课堂状态提示.md)。

**统一的科幻节奏游戏控制台。** 全系统采用深墨蓝底、深蓝底青色亮边主行动、青色智能辅助，紫粉和黄绿色只补充光轨与拍位。备课区是游戏启动器，课堂是同一套视觉语言的全屏舞台；共享长短角、厚底、内凹输入、分层面板和清晰的按压反馈。工作台、游戏库、材料、课件、制作三步、编辑器、资源与设置，以及所有弹窗、空态和错误态必须一致；不能只重做课堂或首页。所有主操作使用深蓝实底、青色边缘与近白文字，默认 / 悬停 / 按下共享同一材质；课堂的开始、暂停、继续、重新播放与备课主操作一致。

课堂以关卡开场、中央教学原文、词序 HUD、四色斜切拍垫、节拍跑道和真实击拍反馈组成场景。主播放键是青色亮边主键，导航和工具分组，避免整屏宽的普通表单工具条；减少无功能的中央留白和零散音符。炫酷感来自构图、纵深、材质、运动和交互共同作用，不以增加粒子数量、描边或假 AI 数字代替设计。

材料、课件和资源页面复用启动器外壳，智能制作复用步骤页，课堂独立占满内容区域。智能感必须对应实际词库、规则、声音与编排成果；不增加聊天机器人、语音识别演示或学生评分。

全系统颜色、组件、课堂控制台和动效以本文的规格为准；实际交付画面与运行录屏单独放在验证报告，不把概念图作为产品通过证据。

普通页面：左侧导航、顶部标题与主操作、主体内容。导航固定为“AI 工作台、游戏库、教学材料、我的课件、资源与设置、关于”，图标配文字；编辑器收窄导航，课堂隐藏平台导航。顶部公共“制作任务”入口展示未完成数量，可打开阶段、失败项与输入版本。进入 AI 制作使用完整步骤页，保留返回工作台和已输入内容。

| 页面 / 区域 | 必须显示的内容                                                                                   | 主操作与返回行为                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| AI 工作台   | 统一智能制作入口、可继续任务与最近课件的真实成果摘要；按当前状态指向确认材料、更新声音或检查导出 | “智能制作”；继续任务查看其成果，继续编辑回到原对象和位置                                               |
| 游戏库      | 单词节拍卡：用途、材料类型、创建入口                                                             | “制作课件”；首版不展示第二游戏或占位卡                                                                 |
| 教学材料    | “材料集 / 常用词库”页签，搜索与标签筛选；材料详情含原文、词条、来源及可接受候选                  | “导入材料”；详情勾词后“用于智能制作”，可编辑、删除或保存所选词到常用词库；空态提供粘贴 / 导入          |
| 我的课件    | 保存和复用已有成果；卡片显示名称、修改时间、准备状态及游戏摘要，复用时可查看保留项与变化         | 主动作“智能制作”，次动作“导入课件包”；可编辑、预演、导出，更多含复制并改编、重命名、导出可编辑包、删除 |
| 资源与设置  | 语音与制作默认、音乐与口号、数据与备份三个分区；声音问题指出受影响项及修复入口                   | 当前分区一个主动作；音色必须可试听                                                                     |
| 编辑器      | 名称、保存状态、词条 / 段落、静态课堂预览、属性和智能建议；检查可直接定位到问题                  | “导出课堂文件”；预演、开始课堂为次级动作                                                               |

课件列表默认最近修改在前；名称模糊检索，可按游戏和准备状态筛选，首版不显示只有一个选项的游戏筛选器。返回列表保留检索、筛选和滚动位置。没有课件时引导制作，不放虚构统计或学生数据。

材料详情进入制作时保留所选顺序，超过 100 条先返回校对选择，不静默截断。没有未保存修改时，“用于智能制作”直接传递所选词条副本；有修改时，按钮改为“保存并用于智能制作”，就近注明会保存材料名及全部词条修改。完整校验并保存成功后，才把所选词条副本交给制作；失败保留输入和选择，不跳转。制作取消不回滚已保存的材料；制作使用内容副本，原材料后续修改不追改课件。

保存常用词使用差异对话框，逐项列出新增 / 完全相同 / 教学字段变化 / 不同义项，默认不覆盖已有值。

复制并改编先在对话框填写名称并选择“沿用原内容 / 替换材料”，确认后才创建独立副本，确认前取消不产生课件。选择替换材料时，创建后进入材料选择；取消替换保留沿用原内容的副本，不影响原课件。具体保留范围以 [AI 复用规则](01-AI赋能与教学规则.md#36-复制课件与换课复用)为准。

| 资源与设置分区 | 内容与操作                                                                                           | 影响范围                                                                                              |
| -------------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 语音与制作默认 | 刷新实际音色、按语言选择和试听；编辑新课默认值，主动作“保存新课默认”；缺音色显示受影响声音与修复入口 | 保存范围见 [制作默认规则](01-AI赋能与教学规则.md#31-三步完成)；仅用于新课件，不改变正在编辑或已有课件 |
| 音乐与口号     | 音乐导入、试听、查看引用和删除；口号按语言 / 用途筛选预览，内置模板只读，本课修改在编辑器完成        | 被引用音乐默认保留，列出使用课件，不静默删文件；现有口号不随模板变动                                  |
| 数据与备份     | 显示数据位置、导出完整备份、选择文件恢复、查看并清理导出副本                                         | 恢复先显示影响、自动备份当前数据并确认；不把单课包当完整备份                                          |

页面空态说明可开始的动作，加载态保留布局，失败态保留输入并提供重试；单项失败不清空已完成结果。资源检查与课件问题面板共用定位和修复文案。

材料详情等使用“保存 / 应用”的表单，未确认修改不写回已保存内容；返回、关闭或 Esc 会丢失修改时，先提供“继续编辑 / 放弃修改”，默认继续编辑。没有修改或当前会话能保留输入时可直接返回。保存 / 应用处理中防止重复提交和关闭导致输入丢失，失败留在原表单；成功后才更新列表。AI 步骤页沿用会话保留规则，课件编辑器沿用自动保存规则，不额外增加相同确认。

### 1.1 主页面的默认布局

普通页面标题区最小高 64px；内容区最大宽 1440px，宽屏居中，编辑器与课堂使用全部可用宽度。标题、说明和主操作构成固定层级，次级筛选紧随其后；窄视口按原顺序换行，不把主动作藏进更多菜单。

| 页面       | 从上到下的内容顺序                            | 默认呈现与细节                                                                                                                                                                                       |
| ---------- | --------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI 工作台  | 制作入口 → 可继续任务 → 最近课件              | 左侧大标题与主操作，右侧全息编排核心、环形底座、悬浮材料卡和声音轨道，标注“智能制作示意”；下方三步路径连接实际操作，不冒充任务进度。无任务不占空面板；依据实际准备状态提供修复、更新、继续或导出入口 |
| 游戏库     | 用途说明 → 游戏卡                             | 单词节拍采用游戏封面式构图、立体词块和清晰的制作入口，说明“高中词汇、示范与跟读、教师控制”，点击进入同一制作流程；首版只有一张游戏卡                                                                 |
| 教学材料   | 页签 / 搜索筛选 → 列表与详情                  | 详情先显示词条与选择数量，再展开原文和来源；窄视口列表进入独立详情，返回保留选择 / 筛选 / 位置；候选义项就近展开                                                                                     |
| 我的课件   | 搜索 / 状态筛选 → 课件卡                      | 卡片依次为名称、游戏摘要、准备状态、操作区；卡片主体进入编辑，预演 / 导出和更多独立可聚焦，不冒泡触发编辑；窄视口单列                                                                                |
| 资源与设置 | 分区切换 → 当前分区表单 / 资源列表 → 结果反馈 | 音色按语言分组，音乐显示来源 / 时长 / 引用数量，备份显示位置与结果；制作默认表单的未提交修改在当前会话切换分区时保留，保存后明确提示影响范围                                                         |

工作台的“继续任务”打开该任务详情，“继续编辑”打开当前草稿，两者分别标明版本。删除、覆盖和恢复操作放在更多菜单或对应数据分区，与智能制作等日常动作分开。

### 1.2 全页面一致性

材料类型按钮表示当前来源类型。重复点击已选中的“词表 / 表格”或“阅读选词”保持原文、预览、列映射、校对修改和选择，不重建结果、不弹重复确认。文本来源切到另一类型已有校对或候选结果时，先说明保留原文、清除本次校对修改与选择，允许取消；只有原文尚无结果时直接切换。原生读取仅提供工作表、未提供原始文本的来源（如 XLSX）不能直接转为阅读文章；点击“阅读选词”须说明需另行粘贴或导入阅读文章，保持当前类型、所有工作表、列用途、校对与选择，不弹出虚假的“原文保留”确认，也不拼接表格冒充文章。来源类型在读取与手工输入边界明确记录，不能因普通粘贴经过预览产生了工作表就阻止其正常切换。规则解释与定位、应用动作分开呈现，不能把整块依据文字做成无明确名称的操作入口。

课堂舞台的装置标签使用“本地节拍核心”等实际职责名称；智能感来自可解释的词库、规则、真实声音编排和教师可控的结果，不由装饰性 AI 字样宣称。

工作台的入口、游戏卡、材料列表、课件卡、制作步骤、编辑属性和设置分区共用同一套按钮、输入、选中、面板、标签和浮层。页面可改变布局密度，不可自行改变主按钮颜色、边角、焦点、禁用或错误含义。导航当前项采用青色导引线与实底，页面主动作使用深蓝底与青色亮边；制作步骤与真实声音轨道使用青色，不用装饰填充冒充完成进度。

每页均检查默认、已有数据、空态、加载、失败、长文本、处理中及可用弹窗；有实际功能的状态才出现。主次操作分明，危险动作保持独立；内凹输入、厚底按钮、面板顶沿和标题图标遵循同一规格。普通备课页面的动态反馈以操作为主，课堂保留完整舞台表现，不让表格正文持续漂移或闪烁。

## 2. AI 助手页面

制作采用[AI 规则文档](01-AI赋能与教学规则.md#3-智能制作流程)中的三步，顶部步骤条、主体输入 / 结果、底部固定动作区；已完成步骤可返回修改，后续依赖结果标记需更新。首步主动作“确认内容”，第二步“一键制作”，制作完成后“进入编辑”，同时提供试听与导出入口。

“智能制作”是流程入口，“一键制作”执行本次已确认的内容和设置；不额外要求教师输入提示词。建议与来源用青色智能说明区，执行动作沿用青色亮边主按钮，处理完成后直接展示课件成果，不以聊天记录代替可编辑内容。

当前会话中返回工作台或切换平台页面，保留步骤、材料、选择和已填参数；重新进入可继续。明确开始另一份材料前说明将替换哪些未完成输入并确认，后台任务仍按原固定版本运行。步骤页底部同时保留返回动作，固定动作区不得遮住最后一行输入或错误。

| 区域     | 交互要求                                                                                                                                                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 内容校对 | 主表展示英文、当前教学释义、候选义项、重点和来源；展开行可编辑词性、单元 / 标签并查看原文位置；候选完整展开，可接受后修订；批量接受只处理符合规则的已选行，数量、排除与已有教师值保护按 [内容校对规则](01-AI赋能与教学规则.md#22-导入限制与错误)执行 |
| 编排设置 | 课件名可修改；预设卡展示目的与主要参数；目标时长、声音模式常显；目标旁注明“不含教师等待和暂停”，结果使用“编排时长”；音色、口号、音乐等放可展开设置                                                                                                   |
| 口号设置 | 按开场 / 转场 / 收尾分组，显示启用开关、语言、原文本和最终口号预览；切换语言后只列匹配的实际音色，缺少音色就近提供修复入口；长度按展开结果检查                                                                                                       |
| 建议卡   | 建议内容、实际原因、影响对象 / 数量、前后值、“应用 / 忽略”；计时依赖齐全时显示时长变化，否则标“声音准备后计算”；过期显示“需重新检查”及检查动作，禁用应用                                                                                             |
| 改编差异 | 新增、修改、删除、锁定冲突分别列出；不允许修改的项解释原因；“应用全部 / 放弃”                                                                                                                                                                        |
| 制作进度 | 实际阶段、完成数 / 总数、当前处理项、失败项与取消；允许返回其他页面，任务入口保留                                                                                                                                                                    |
| 制作结果 | 确认补全项、重点词、段落、实际编排时长、声音数量及问题清单；可定位修改或只重做失败项；明确标注制作所用版本                                                                                                                                           |

无结果时提示换关键词或自建词表；无可调整项说明原因。声音缺失、缺词义、参数非法分别使用对应文案，不全部归为“AI 失败”。首次配音前出现实际音色列表与试听，不能仅显示一个无依据的“智能音色”。

内容校对与材料详情在可用内容宽度不足 1000px 时使用两层条目：上层保留选择、英文和重点，下层保留当前教学释义、候选数量、来源摘要与详情入口；长文本继续换行。候选义项、原文位置、词性和单元 / 标签在本条内展开，不把整表缩字或制造整页横向滚动。每页 50 条，分页、选择数量、批量栏和错误定位仍可达；展开、收起和切换布局不丢失输入或选择。

智能辅助统一采用“候选 / 建议 → 查看依据与影响 → 接受 / 忽略 → 已应用结果”的交互。来源标签与规则理由常显，长详情可展开；“已接受”与“仅推荐”不能使用同一状态。助手不替教师默认选择教学义项，具体接受范围以 [内容校对规则](01-AI赋能与教学规则.md#22-导入限制与错误)为准。

各页复用同一种智能结果结构：**发现什么 → 为什么 → 会改哪里 → 怎样处理**。例如“重点词多练一轮”须同时列出适用词条和轮数前后值；“可复用声音”须给出实际匹配数量。规则依据不单独充当可操作按钮，应用、定位和查看详情各有明确名称。无匹配、无差异和无可调整项分别说明原因，不生成空建议卡；缺少依据时允许手工编辑，不编造智能结论。

“换一版”的差异页先显示本次改编范围，再列实际变化；手改口号默认保留，只有教师打开“允许替换手改口号”后才列为可替换项，锁定口号始终保留。范围改变后重新预览，不沿用上一范围的确认结果。

差异使用教学用语和单位，例如“轮数：2 轮 → 1 轮”“预计节省：2.4 秒”，不显示内部 JSON、标识或随机标记。已应用 / 已忽略的建议可查看原差异，不能再次应用；需重新检查时提供检查动作，不自动替换教师输入。成果摘要区分候选、已确认、新制作和复用，计数按 [成果口径](01-AI赋能与教学规则.md#35-改编结果与复现)统一。

差异对话框同时列出实际修改项和因手动 / 锁定而保留的项；确认时重新检查依赖，已过期则保留预览并要求重查，不部分应用旧差异。检查面板按阻塞错误、声音需更新、待制作、提醒分组，点击问题聚焦对象及字段；窄布局先切换对应区域、展开属性抽屉，再滚动并聚焦，关闭抽屉保留当前对象与位置。禁用动作旁显示原因与修复入口，不能只靠悬停提示。制作、应用与重新检查各自防止重复提交，后台处理不丢失教师的新输入。

内容校对和材料详情的折叠行遵循相同定位规则：收起时保留错误标记与数量，点击问题先展开对应行，再滚动到字段。展开、收起或翻页不清空编辑输入；首次提交失败按错误摘要定位，后台重查不自动展开其他行或抢走当前焦点。

制作期间继续编辑产生新修订时，任务仍展示真实进度。完成后显示“制作版本与当前版本已不同”，提供“查看旧成果（只读） / 基于当前内容重新制作”，不以“进入编辑”覆盖当前草稿。重新制作复用仍匹配的声音；源课件仍在时，任务详情可返回其当前草稿。

旧成果页显示原课件名、制作版本、原内容与该任务实际成功 / 失败的声音，可试听和检查预演，不提供编辑当前草稿或应用旧成果的按钮。预演退出“返回成果”；源课件已删除时显示说明，返回入口改为工作台。任务清除前仍可查看，不能借同名课件代替原输入。

历史任务的原始内容已无法恢复时，说明“原制作内容已不可恢复”，保留任务记录及可独立试听的成功声音；隐藏依赖原始内容的编辑 / 预演操作，不用当前草稿或同名课件补造原内容。

## 3. 编辑器与编辑反馈

### 3.1 区域职责

```text
顶部：返回 / 名称 / 保存状态              预演  开始课堂  导出课堂文件
左侧：段落与词条       中间：静态课堂预览       右侧：当前对象属性
                     段落时间与准备状态              / 智能建议
```

词条区域显示英文、释义、重点、轮数、声音状态。三栏 / 双栏布局的窄词条区使用两行列表：首行英文、重点，次行释义、轮数和声音状态；详细字段在属性区编辑，不把六列挤进 248px。独立词表视图使用完整表格。当前编辑对象只用一项高亮；复选框表达多选，与当前对象区分，多选后出现批量栏。未勾选行不受影响，字段混合值显示“多个值”。

表格全选明确标为“全选本页 / 当前结果”；跨页或筛选后保留选择时，同时显示总数和当前不可见的已选数，提供“清空选择”。批量动作始终作用于显示的完整选择范围，不能把隐藏选择悄悄带入操作。

属性按“内容 / 练习 / 声音 / 口号”分组，当前对象无关的分组隐藏。“内容”含英文、教学释义、词性、单元 / 标签及来源详情；“练习”含重点、轮数、跟读规则 / 拍数、文字示范拍数和“单词 / 短语”标记及来源；“声音”管理配音 / 录音，“口号”编辑对应阶段的文本与启用状态。全课节奏、展示、推进方式与声音模式在预览上方可见；高级设置收起。切换对象不重置输入，错误在字段与对应行同时保留。

词性、单元是可空文本字段，标签支持中英文逗号分隔；校对展开行、材料详情和编辑器使用相同名称与编辑规则。词性 / 释义修订保留原词库候选，单元 / 标签修改不重做英文配音；字段长度与控制字符按 [内容输入规则](01-AI赋能与教学规则.md#22-导入限制与错误)校验。来源详情分别展示原材料名称与位置、词库名称与版本、原候选和教师修订状态，不能将词库名称显示为原文来源。

批量栏只提供重点、单词 / 短语标记、轮数、跟读规则 / 拍数、文字示范拍数、系统配音音色 / 语速、锁定和删除；英文、释义、录音绑定逐项编辑。更换系统配音参数不替换手工录音。直接批改属于教师明确编辑，可改锁定项；智能建议仍遵循锁定。整批先校验，任一项不合法则不应用，指出具体项；成功应用及撤销均按一次操作处理。

批量表单默认不勾选任何修改字段；“多个值”和未选择字段的留空均表示不修改，不写成空值或默认值。勾选要修改的字段后必须提供合法值，留空按错误处理；“恢复预设 / 使用本课声音默认 / 解除锁定”分别使用明确选项，不由留空或未勾选推断。应用前显示实际条目数与修改字段，筛选隐藏的已选条目同样计入。

声音属性区分“系统配音 / 导入录音”。系统配音的音色和语速各自显示实际值及“沿用本课默认 / 条目单独设置”来源，各自可恢复默认；允许音色独立设置而语速继续继承。跟读锁定显示锁的是预设公式还是手动拍数，不能只用一个锁图标代替范围说明。

文字领读的条目声音栏显示“教师示范”，不把已关闭的示范声音标为待制作或需更新；已启用口号与音乐的问题仍进入课级检查面板。

| 锁定范围 | 智能操作须保留的内容                                | 教师修改后的处理                           |
| -------- | --------------------------------------------------- | ------------------------------------------ |
| 位置     | 当前段落内的位置，不参与智能洗牌                    | 手动移动后锁定新位置                       |
| 练习参数 | 明确勾选的 BPM、轮数、跟读规则 / 拍数或文字示范拍数 | 修改后保留锁定及手动来源                   |
| 声音     | 对应的声音选择及已匹配录音                          | 文本改变仍使旧声音失效；更新声音须明确操作 |
| 口号     | 指定口号文本和启用开关                              | 手动修改后保留锁定，声音按依赖重新检查     |

BPM 是课级参数，在全课设置锁定；其余锁定随所属条目或口号显示。锁定不会使无效数据通过检查。

### 3.2 操作与修改范围

| 操作         | 行为与边界                                                                                                                                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 新增 / 编辑  | 新行聚焦英文；单行字段 Enter 结束本字段编辑并校验，不隐式触发整页确认、制作、替换或导出；多行文本 Enter 换行，Tab 换字段；中文输入法选词时不结束编辑；错误在字段旁显示 |
| 导入 / 粘贴  | 先校对再追加 / 替换；显示数量与关联段落；不直接清空原表                                                                                                                |
| 保存为常用词 | 单项或多选后打开保存差异；只保存教师确认的教学字段，不保存本课轮数、声音锁定或播放进度                                                                                 |
| 排序         | 拖动手柄并提供上移 / 下移；保留条目标识和声音引用                                                                                                                      |
| 段落         | 新增、命名、排序、移动词条；删段落时选择移入其他段落或连同词条删除，列出影响                                                                                           |
| 删除 / 撤销  | 普通编辑、排序、批量操作、建议应用可撤销 / 重做；Ctrl+Z / Ctrl+Y 作用于编辑器，文本输入中保留原生撤销                                                                  |
| 锁定         | 显示锁定对象与范围；只限制智能操作，教师仍可修改；冲突不得静默跳过                                                                                                     |
| 试听         | 单词、口号、整段可试听；新试听停止旧试听；预演、课堂、编辑试听互斥                                                                                                     |
| 预演         | 检查当前内容与声音后运行；退出回到原编辑位置；不另建一份课件                                                                                                           |

会话内最多保留 50 次内容操作的撤销记录。同一字段的一次连续编辑合并为一条，单行字段 Enter 或离开字段时结束；多行文本中的 Enter 换行不拆分该次连续编辑。自动保存不另增加记录，输入框内仍用原生文本撤销。整次批改、排序或建议应用各算一次。撤销后重新判断声音匹配，已有匹配音频可复用，不撤销文件导出、备份等外部操作。

| 修改                         | 保留                         | 需更新                                         |
| ---------------------------- | ---------------------------- | ---------------------------------------------- |
| 中文释义                     | 英文声音、词序               | 显示文本；引用该字段的内容                     |
| 英文                         | 其他词和声音                 | 当前配音、依赖项和编排                         |
| 课件名 / 条目数量            | 未引用该值的声音             | 使用相应占位符的口号、其声音及编排             |
| 节奏、轮数、跟读拍数         | 声音文件                     | 时间安排与总时长                               |
| 音色、语速                   | 文本、词序与手工录音         | 受影响的系统配音与编排                         |
| 口号                         | 词表和其他声音               | 当前声音、时长与插入位置                       |
| 音乐选择 / 启用              | 词条声音与时间安排           | 音乐素材清单和混音，不改变编排时长             |
| 声部音量 / 静音              | 启用状态、素材清单与时间安排 | 仅混音；不以静音跳过资源检查或打包             |
| 声音模式、示范或口号启用开关 | 其他素材                     | 当前模式所需清单与时间安排；节拍开关不改变时长 |
| 展示模式                     | 内容、声音、时间安排         | 仅画面                                         |

编辑预览明确标“静态预览”，即时展示所选词条、展示模式和状态，不自动发声或推进词序；声音仅点击制作 / 更新后生成。声音过期显示“声音需更新”，旧声音不能按新文本试听。“预演”经完整检查后进入实际运行会话，退出恢复编辑对象和位置。预演、开始课堂、课堂 HTML 导出默认固定并检查当前草稿，完整后保存已准备修订；有问题时先修复。选择使用上次已准备版本时，必须明确操作并显示版本差异，不能静默回退。

编辑建议就近显示在当前对象属性旁，涉及全课的建议进入同一建议面板；切换对象保留尚未处理项。应用后标记结果并复查，依赖变化后按 [建议有效期规则](01-AI赋能与教学规则.md#31-三步完成)更新，不自动重新配音或替教师接受新建议。

### 3.3 状态与反馈

| 类别     | 状态                                                                  | 显示规则                               |
| -------- | --------------------------------------------------------------------- | -------------------------------------- |
| 保存     | 保存中 / 已保存 / 保存失败                                            | 固定在课件名旁，与制作进度分开         |
| 内容准备 | 草稿 / 声音待制作 / 声音需更新 / 需修复 / 可上课                      | 列表与编辑器一致；细节问题进入检查面板 |
| 任务     | 排队 / 制作中 / 正在取消 / 已取消 / 部分失败 / 失败 / 已完成 / 已中断 | 展示阶段、完成数量和下一动作           |

内容主状态按“需修复 → 声音需更新 → 声音待制作 → 草稿 → 可上课”取首个适用项：非法字段、已引用素材丢失 / 损坏或解码失败为需修复；当前启用声音已有旧音频且实际文本 / 合成设置已变化为需更新；必需声音从未生成则待制作；资源完整但当前版本尚未完成检查为草稿。无关释义修改不使英文声音过期，关闭的声音不参与状态计算。面板同时列出全部问题；仅当前版本检查通过才显示可上课，历史已准备版本另列，不代替当前状态。

草稿停止编辑 500 毫秒后自动保存，Ctrl+S 立即保存；离开或正常关闭前完成保存，失败允许重试或留在页面，不能直接丢弃输入。异常退出恢复最近一次成功保存的草稿，不承诺恢复尚未落盘的输入。

草稿允许保存空英文、未完成数字等编辑输入及错误位置，重新打开继续修改；无效输入不作为可运行参数，也不能发布到常用词库。预览明确标注错误，保留最近有效画面不代表当前内容可上课；准备、运行和课堂 HTML 导出仍要求当前输入全部合法。

同一提交动作处理中禁用重复触发，但不锁死整页编辑；取消请求发出后显示“正在取消”并禁止重复取消，后端确认后才显示“已取消”，成功产物仍可查看。成功 Toast 显示约 4 秒且不抢焦点；保存失败、缺素材和版本冲突使用持续提示及修复入口。导出完成展示成品位置与“打开检查 / 打开文件夹”，不只弹一条短提示。独立“导出可编辑包”允许保存未完成草稿，不以 HTML 配音检查通过为前提。

终态任务可“清除记录”，先说明未应用声音不再保留、可由缓存清理回收；已经保存到课件的声音不受影响。运行中的任务须先完成或确认取消，不能用清除记录代替取消。

普通编辑依靠撤销；删除课件、替换内容、覆盖文件、恢复备份显示具体影响并确认。对话框默认焦点放安全操作，关闭后回到触发控件。提交多项错误时聚焦错误摘要，摘要可跳到字段，已输入内容保留；字段错误同时就近显示，并与输入控件建立无障碍关联。后续失焦校验、自动保存或后台检查只更新提示，不反复抢走正在输入的焦点。

编辑器保存冲突时保留本地输入并暂停该课件的自动重试，持续标“本地修改未保存”；提供“查看已保存版本（只读）”“另存本地副本”“继续编辑”和“放弃本地修改并重新载入”。另存先确认副本名称，使用本地草稿而非已保存版本，沿用[副本身份与事务规则](04-技术架构与数据规范.md#41-主要数据对象)，成功后进入独立副本；失败保留原输入。重新载入先确认会丢失的本地修改，不提供强制覆盖；查看或取消均不改变本地内容。

### 3.4 导出对话框与结果

默认使用当前草稿，显示名称、保存版本、声音模式、准备状态和问题入口；有上次已准备版本时，额外提供明确的版本选择，展示其保存时间及与当前草稿的变化摘要。选择旧版仅影响本次 HTML 导出，不回退编辑内容。检查与双文件快照规则见 [导出规范](03-课堂运行与便携交付.md#42-导出与成品检查)。

“同时保存可编辑课件包”和“导出后打开检查”显示各自当前值；处理中展示实际阶段，防止重复提交。可返回其他页面，任务继续执行，从公共任务入口查看结果。结果区按 HTML / 可编辑包分别列出状态、实际位置与对应动作；包不显示课堂播放入口，单项失败不遮掉另一项成功。

本机成品已生成但复制失败时，提供“重新复制”，使用同一成品并再次校验，不混入后来编辑；本机成品尚未生成则提供“重新导出”，重新选择并固定版本，显示将使用的内容，不承诺恢复已经释放的旧导出输入。打开检查、打开文件夹及失败原因就近显示。

公共材料导入的整理、文件读取及确认失败后，将键盘焦点移到可聚焦的错误摘要，并仅滚动最近的可滚动正文，使说明进入实际可视区。模态内只调整正文滚动位置，不移动外层对话框或背景页面；独立制作页使用页面滚动并避让固定工具区。同一错误重复触发仍重新定位，错误清除、来源切换或卸载取消待处理的定位回调，不改变教师输入、校对与选择。不能只用 DOM 可见断言代替窄屏可视区验收。

备课任务完成、失败和重要保存结果通过状态区提供简短、带对象名称的读屏通知，不移动焦点，不随每项进度重复播报。课堂拍位、高频时间更新与逐拍高亮不连续播报，避免干扰教学声音；按钮名称、当前播放 / 暂停状态仍可读取。

触控区域至少 44 × 44px，邻近按钮间距至少 8px；鼠标与触控共用完整命中范围。焦点环 2px、外留 2px 间隔，不能被固定栏遮挡；快捷键不与输入法、文本输入和弹窗冲突。

### 6.2 课堂布局

开始页按 [课堂开始规则](03-课堂运行与便携交付.md#21-状态流转)显示课件摘要、声音模式和课堂推进模式，提供“测试声音 / 停止测试 / 开始课堂”。新课默认自动推进：开始后连续完成示范、跟读、转场和下一词，直至收尾完成，无需逐词点击。课堂设置可选逐词等待教师，此时非末词完成后主按钮显示“继续下一词”，经原编排转场进入下一词；独立“下一词”按钮和右方向键始终用于直接切词。点击开始后检查内容和必需素材，启用声音并准备首批资源，资源准备期间不推进；首次准备失败留在开始页并定位。开播后的资源异常按 [声音与资源规范](03-课堂运行与便携交付.md#3-声音与资源)暂停在待播阶段，准备就绪后由教师继续，不要求开始前整课解码。

宽视口开始页采用左右关卡布局：左侧为标识、课件标题、真实词数 / 编排时长 / BPM / 推进方式和启动动作，右侧为大尺寸 SVG 能量装置与本课前三个词的悬浮卡；不足三个时按实际数量显示，没有词不虚构内容。宽度不超过 700px 时收为单列并隐藏右侧装置；低高度时先压缩标题、留白与装置，保留摘要、错误与操作可达。开始页可低速漂浮与旋转，不自动发声或推进。

顶部为课件名、段落、词条进度和运行状态；长课件名允许换行，超长连续文本可按字符换行，不挤走进度或操作；中间为英文、可选释义与“准备 / 示范 / 跟读 / 等待教师 / 已暂停”；底部为上一词、播放 / 暂停、下一词、重读和全屏 / 退出全屏，课堂设置含自动 / 逐词、显示词义、音量、节奏、展示模式、循环和结束。

课堂按“顶部状态 / 中部教学内容 / 底部控制”分区。低高度时先压缩上下留白与拍位区，控制区空间不足则分两行，上一词、主播放键、下一词和重读保持相邻；设置与全屏位于另一行。各行按实际高度给教学区预留空间，不将控制栏浮盖在词义上，不以缩小按钮命中区域换取空间。普通课件在可用视口至少 911×480 时，开场不出现横向或纵向滚动条；超长课名或修复信息确实超高时，仅正文区域允许纵向滚动，开始、测试声音与返回动作保持可达。

运行控制台采用宽度不超过 1160px 的悬浮分组，宽屏居中，避免横贯全屏的办公工具条：左侧显示真实完成数量与自动 / 逐词模式，中间为上一词、青色亮边播放键、下一词和重读，右侧为设置、全屏及可用的返回动作。主播放键采用 56px 高的长短角按钮、普通播放 / 暂停图标与当前动作文字，附低对比度 `Space` 提示；主键、前后切词和工具共用深色实底、青色边缘、长短角与厚底，主键以更亮边缘和稍高尺寸突出，不另造暖色圆胶囊；前后切词和重读为独立厚底工具键，工具组与播放组有明显间隔。图标键有明确无障碍名称、可见或悬停 / 聚焦可读的短标签，触控不依赖提示才能使用。窄窗口优先隐藏重复的键位说明与次要描述，不隐藏控制功能，不强制扩大页宽。

中央教学区带低亮角标、阶段轨道和能量底座，英文、释义和拍垫组成连续纵向构图；不在中间留下缺少层次的空白。教学原文稳定，AI 标记只表示实际规则编排与自动衔接，不显示“正在识别”、虚构置信度或假波形。词序 HUD 保持细窄，当前词配实底与导引光，邻词不争夺中央教学层级。

课堂外层和内部滚动区域均不得横向溢出。门户光晕、旋转轨道和悬浮卡在装置边界裁切，不把绘制范围计入开场滚动宽度；光效安全留白随布局内距使用 24 / 18 / 12px，不超过对应内距。可用高度不超过 740px 时先缩小装置、装饰标题和间距，不超过 560px 时再紧凑开场说明与动作区；教学正文的字号适配规则保持独立。布局检查必须使用扣除浏览器工具栏后的实际可用尺寸，并检查内部容器的可滚动量，不能只检查整页宽度或隐藏滚动条。

开场顶部提供课堂设置；首次开局使用已确认的本课安排。运行中打开课堂设置暂停播放，已暂停、等待教师和异常状态不改变；关闭不自动播放。音量等合法草稿可即时试听，全部设置仍由底部「完成设置」统一保存，BPM 按运行规则生效。自主齐读的「练习安排」提供逐词／实际范围的轮数、每轮总拍数和每次朗读占用拍数，实时说明每轮读几次和真实编排时长；间隔是词与词之间的额外拍，不混入每轮。手动／锁定保护、统一校验、课中下一词生效及本地保存遵循 [课堂拍数与朗读次数复查](17-课堂拍数与朗读次数复查.md)。浮层内操作不触发背景快捷键，关闭不自动继续或切词，Esc 先处理当前浮层。

声音标签来自实际编排使用的示范／口号，不把仅有口号的课堂称为示范；课前专属设置运行中禁用时，就近显示原因及返回开始页的处理方式，不仅藏在帮助浮层中。

齐读逐词／范围两栏的轮数说明保留相同的两行基础空间，较长错误可继续展开；后续拍数输入对齐，避免说明换行造成错位。窄窗可见标签采用「每次朗读占拍」，帮助与无障碍名称保留完整含义，不缩小点击区域或隐藏输入。

课堂临时英文／释义复用同一选词，放在练习安排的逐词区，直接编辑并由底部统一完成。当前运行词不被草稿或待生效文本替换；配音失配须明确提示并由教师选择整课文字领读。细节见 [课堂临时词语调整](18-课堂临时词语调整.md)。

课堂设置采用同一控制台材质：清晰的标题与收起操作、内凹表单、青色选择 / 焦点、独立节奏和声音控制区域；结束操作使用危险色并与日常设置留出间隔。练习安排中的拍数与轮数共用选词／范围，使用对齐的直接输入和选择，不再用勾选激活隐藏拍数字段；共同值、混合值、实际修改与保护反馈明确区分，单项还原不移动其他输入。低高度时仅设置正文纵向滚动，标题与动作完整可达，保留所有原生标签和键盘语义。

调速区区分“当前 100 BPM”和“120 BPM 将于下一词生效”；等待期间重读仍显示本词当前值及待生效值。暂停中调整显示“继续后从当前阶段起点生效”；校验失败就近说明原因，保留原值与进度，不显示已经调速成功。实际生效后清除待生效提示。

展示模式仅有“居中大词”和“节奏方块”，新课默认节奏方块：前者突出中央英文、能量环轨和紧凑拍位；后者保留完整英文 / 释义，下方青 / 紫 / 粉 / 黄绿色的立体拍垫呈错落深度，随真实拍位产生高亮、落拍光柱、冲击环和碎片，并逐个留下当前词的轨迹。已有课件及主动保存的新课偏好沿用原模式。长词可在词槽内省略，中央教学原文仍完整显示。配音／文字领读的拍格跟随基础拍；自主齐读的词槽表达一次朗读，4 拍、每次占 2 拍即两次朗读提示，每个词槽持续两拍，并另以基础拍进度说明真实四拍。超过四个朗读提示按窗口显示，不堆满小框。词槽不代表音节、音量或正确率；切换只改布局，当前词、声音与进度不变。

四拍装置采用统一的斜切面、厚底、顶沿能量条、刻度与跑道连接，避免四张普通圆角卡片；编号始终可读，当前拍的能量边、落拍下压、局部光柱和有限碎片形成主反馈。示范与跟读通过阶段标签及色调区分，已到达轨迹不等于学生得分。背景减少无关大音符，使用纵深跑道、低速扫光和外部节拍驱动的局部冲击，光效不穿过单词主体。

拍垫按 [连续拍序规则](03-课堂运行与便携交付.md#1-节奏与时间计算)显示同一轮的真实进度：示范 2 拍、跟读 2 拍必须依次经过“示范第 1、2 块 → 跟读第 3、4 块”，不能在进入跟读时重回第 1 块。一轮不固定为 4 拍，超过 4 拍继续循环，不能为补齐方块添加等待或延长声音。新轮、新词、直接切词和重读回到第 1 块；普通暂停 / 继续保留拍位，恢复准备独立显示后回到原位置。轨迹、高亮与爆发使用同一连续拍序，两种展示模式保持一致；改速仍按运行规则生效。

运行画面顶部的词序 HUD 显示当前与相邻词，配位置编号和当前高亮；完成进度按完整完成过的条目计算，不能用“当前词索引”代替已完成数。背景由透视网格、侧向光束、能量环、Canvas 星尘连线和拖尾组成，爆发发生在教学区下沿与拍垫周围，中央原文保持稳定可读。教师控制栏常显，口号仅在独立阶段替换中央内容，跟读期间不滚动鼓励语。

真实节拍准备阶段显示大号倒数：首段 3 / 2 / 1 / GO，后续段和启用的恢复准备为 1 / GO；规则见 [准备倒数](03-课堂运行与便携交付.md#21-状态流转)。倒数位于教学区，不代替资源加载状态；暂停时冻结，关闭特效时仍能读取当前拍位。

课堂以教室大屏、远距离观看为目标。中文释义是核心教学信息：默认 64px、700 字重、近白正文色，与英文共用悬浮文字、轻微立体阴影和柔和青色光晕；不使用独立方块、底框、下划线或灰色辅助文字样式。多行释义自然换行且不超过教学区。英文与中文之间保留明确间隔，教学区中心维持低亮背景，发光不模糊字形。1920×953 下常见单词及短释义使用 144/64px。

课堂英文和释义按同一顺序适配：先保留原文并换行，再压缩非教学装饰留白，仍放不下时按英文 / 中文成对档位降低字号，取可完整显示的最大组合，不能为保留超大英文先把中文压到最小；内容区宽度不足 1000px 或可用高度不足 640px 时可用窄视口档位。最低档仍放不下，仅教学内容区纵向滚动，控制栏保持可达。超长连续文本可按字符换行，不改存储文本或配音，不裁切、不显示省略号。编辑器静态预览按自身内容宽度复用此规则，不按整个窗口宽度放大文字。释义默认显示、可折叠；课堂不展示材料路径、备课建议卡或技术错误栈。

结束页以能量徽记、完成标题与三张记录卡组织，显示“练习完成 / 已提前结束”、实际用时、已完成条数 / 总条数和主动重读次数，不给出得分、排名、正确率或学情结论。提供“重新播放”；桌面预演 / 课堂另提供“返回编辑”，恢复原对象和位置；独立 HTML 提供“回到开始页”，不出现不可用的编辑入口。返回或重播前释放旧音源，重播建立新的运行统计。

可用高度不超过 560px 时，结束页把徽记与标题并排，三张统计卡保持横排，说明与操作各占独立一行。可用视口至少 911×480 时，标题、统计、重新播放与返回动作须同时完整可见，无整页或结算区域滚动；保留原有字号和按钮命中尺寸，不缩放整页或隐藏滚动条来掩盖裁切。自然完成与提前结束使用相同布局。

## 逐页交互复核补充（2026-10-20）

- 搜索结果为空与资料库本身为空必须明确区分：已有材料、常用词或课件被筛选隐藏时，提示调整筛选，不误导教师重新导入。三类列表均在搜索栏提供同名“清除筛选”，只重置当前列表的检索条件及分页，不修改保存数据；清除后焦点回到搜索输入，便于继续键盘操作。
- 宽屏和收窄导航使用同一品牌图形；64px 导航轨道内图标必须居中且完整，不能沿用完整侧栏的文字留白使图形被 max-width 被动压小或偏离中心。编辑器与 1000～1199px 普通页面遵守相同尺寸。
- 词表/表格与阅读选词是二选一模式，除视觉选中状态外，按钮须通过 aria-pressed 暴露当前选择，所有导入入口一致。
- 公共错误 Notice 默认采用 alert 语义，不抢焦点；调用方已有显式 role 时尊重其设置。普通说明与非错误通知不默认升级成警报。
- 逐页截图须等待短暂入场动画完成或在截图时完成有限动画，避免把半透明入场帧当成最终界面。动效行为仍单独用真实时间测试，不能仅依据静态画面宣布通过。

成功 Toast 统一置于视口顶部安全留白，不占用弹窗底部操作区；提示本身无操作，不接管指针事件，不抢焦点，约 4 秒后消失。失败提示仍在上下文中持续显示，不能用短暂 Toast 替代。

## 首发游戏收束与特效生命周期（2026-10-21）

单词节拍自然完成显示完成徽章，提前结束使用中性停止图标及“已提前结束”，不使用成功勾暗示全部完成。两者均展示控制器真实统计，附“仅记录课堂运行，不评价学生掌握程度”。说明与统计摘要同排、允许自然换行，不固定增加一行；911×480 的普通结算必须保持无内部滚动。结果标题接收程序化焦点，随后 Tab 到重新播放；普通设置关闭仍归还设置入口，设置内结束直接转入结果标题。重新播放从零统计开始，返回开始页聚焦开始按钮。

自然完成可在徽章两侧出现一次能量碎片收束，最多 24 枚，单枚不超过 900ms，最多错开 120ms；动画只使用位移、旋转和透明度，不盖住正文、不拦截点击、不阻塞重播。采用共享完成动效时长变量和 game-ease；提前结束无庆祝。关闭特效、系统减少动态或页面隐藏时立即移除碎片，本次结果不在重新启用后补播。静态徽章与结果始终保留。

星尘场暂停时停止 rAF、指针响应并丢弃待播爆发；静态画面仍响应实际尺寸变化，每次仅重绘一帧，不以持续动画维持尺寸。动态场自身连续 8 个绘制帧耗时超过 8ms 时，本次挂载降为低密度，减少星尘、连线、爆发并取消流星；不提高已公布的数量/像素预算，也不改变教学时钟。性能测量只计算装饰绘制，不能根据测试伪造课堂时间。

环轨保留三层发光椭圆、静态弧线、小尺寸轨迹光点及真实拍击扩散。容器使用实际扁椭圆尺寸，不再将大正方形旋转面通过 3D 透视压扁；轨迹点沿椭圆移动，避免为整圈边缘持续合成巨幅图层。暂停、等待、隐藏及减少动态时冻结轨迹；缺少 CSS 路径动画支持时保留静态光点和完整文字，不影响教学时间轴。

全特效对拍验收同时记录真实 AudioContext 调度、DOM 提交和对应下一次 rAF 呈现机会，后两者分别报告样本数、P95、最大值和首末误差差值。全特效下一次呈现机会相对拍点的最大延迟仍须小于 100ms；仅 DOM 达标、减少动态达标或自动降级达标均不能代替完整特效验收。rAF 不等于屏幕像素实际呈现，扬声器及显示器物理延迟需另测。性能复测应使用前台、焦点和独占浏览器窗口，保留失败样本与合成 trace。
# 课堂异常状态补充（2026-10-21 二次复查）

- 小窗口控制台必须同时考虑应用课堂的“返回编辑”和离线课堂的较少按钮。优先收紧工具按钮横向内距与组间距，保持44px触控高度，避免多行控制台挤压短词、倒数及组名；长文本仍使用既有全文滚动回退。

- 声音准备或播放失败时，已开课舞台显示“播放已中断”，不得继续把当前阶段标签呈现为正在示范或跟读。保留词语和拍位，便于教师知道恢复位置。
- 故障反馈采用既有 error 颜色、警告图标和 `role="alert"`，同时写明恢复动作；普通设置反馈仍使用 `role="status"`。弹窗打开时反馈只保留在弹窗内，避免重复告警。
- 开始前失败指向“开始课堂”；运行中失败指向“重试当前阶段”；设置打开时说明先关闭设置。恢复后移除故障提示和错误样式，不添加阻塞动画或额外确认。
- 故障不触发成功粒子；现有停止动画规则继续生效。720×480、911×480 与常见投屏尺寸需保证提示、词语和恢复操作可读、可达。


本轮展开入口、真实任务进度及课前课堂设置的交互补充见 [11 · 展开入口与课前设置](11-展开入口与课前设置.md)。课堂运行中打开设置会暂停，收起后由教师继续；等待教师和异常状态保留原状态。

轮数调整与设置说明遵循 [12 · 课堂轮数与设置说明](12-课堂轮数与设置说明.md)。轮数区优先展示当前词、真实编排时长、逐词及范围操作；帮助按钮独立于输入标签，支持悬浮、聚焦、点击和先收起说明的 Esc 行为。短屏内容滚动，帮助层在模态边界内避让；错误与生效范围不藏入帮助层。


## 嵌套模态层级复核（2026-10-22）

共享 Modal 以 React 上下文传递层级：根遮罩／内容为 100／101，每层嵌套增加 2，确保子遮罩覆盖父内容、子内容位于其遮罩之上。Portal 的 DOM 插入先后不能决定嵌套确认的可见顺序。不使用页面专属 z-index 或无界递增的全局计数。FeedbackProvider 发起的全局安全确认使用保留层 300／301，高于通常嵌套表单；帮助层继续使用既有层级。

层级只负责呈现，不改变 Radix 的模态、焦点限制、背景禁用和滚动锁生命周期。子弹窗开启时安全取消动作先获得焦点；Esc 仅关闭最上层，取消后回到发起按钮且保留父表单。全部关闭后归还原页面焦点并释放 body 滚动锁。底层按钮不能穿透点击。

影响调用方为 App 的导航／任务／常用词等弹窗、Editor、Wizard、MaterialsPage（含材料详情与常用词）、SettingsPage、TimePlanning、LessonExportDialog（含导出任务）、MusicImportButton、ImportPanel 及 FeedbackProvider。回归覆盖材料导入内的材料类型确认、全局放弃确认、导出确认、音乐多音轨选择；普通单层弹窗的尺寸、外观和操作顺序保持原约定。无原生能力的浏览器回归不能代替真实 Windows 音轨提取，但应验证选择弹窗的共享层级和生命周期。
