# 03 · 课堂运行与便携交付

学生自主齐读、独立朗读占拍与可选音乐对拍的新增规则见 [07 · 学生自主齐读](07-学生自主齐读.md)。本页示范／跟读公式继续用于原有两种模式，不用于自主齐读。自主齐读 HTML 无变速设置时声明运行核心版本 2；含音乐倍率、保音高设置或目标与原始 BPM 不同的课件声明版本 3。产品版本仍为 1.0.0。音乐变速与校准见 [08](08-辅助能力与音乐变速.md)。

## 1. 节奏与时间计算

预设与允许范围以[AI 教学规则](01-AI赋能与教学规则.md#32-单词节拍预设)为准。当前模式启用的声音先制作或导入，再按真实时长编排；文字长度只可作为制作前的参考，不作为最终音节数或音频时长。

| 量 | 计算与含义 |
| --- | --- |
| 每拍时长 B | `60,000 / BPM` 毫秒 |
| 示范占用拍数 M | `ceil((D + 150) / B)`；D 为真实音频毫秒数，150 为尾部缓冲，ceil 为向上取整 |
| 跟读拍数 R | 按当前预设和短语标记取得，或采用教师手动值 |
| 一轮时长 | `(M + R) × B`；示范开始发音，其余不足一拍的时间留空 |
| 单词练习时长 | 轮数 × 一轮时长 |
| 口号时长 | 与示范相同，按真实时长加尾部缓冲后向上取整到拍 |
| 整课编排时长 | 各词练习 + 各次准备 + 已启用口号 + 词间转场；各项只计算一次 |

顺序为开场口号 → 整课准备 → 当前段词条练习 → 词间转场 → 后续段准备 / 练习 → 收尾口号。段落边界有口号时先播放口号，再进入段准备；相邻段之间不再额外添加一次词间转场。末词后直接进入收尾，不添加无用途的尾部转场。关闭口号即从编排移除。

空段落可保留在草稿中，编排跳过空段及其准备 / 口号；首个非空段使用整课准备，后续非空段使用段准备，课堂段落进度只计非空段。全部段落为空时允许保存草稿或可编辑包，阻止开始和课堂 HTML 导出。

文字领读用“教师示范”展示拍数替代音频占用拍数：普通词默认 2 拍、短语 3 拍，均可调整为 1～32；跟读仍按当前预设计算。类型切换与恢复预设时的示范拍数更新，遵循 [预设与手动值保护规则](01-AI赋能与教学规则.md#32-单词节拍预设)。配音较长时保留完整声音；计算所需跟读超过允许上限时提示教师调整音频 / 内容，不静默截断或强行读快。

四色拍垫表示第 1～4 拍，不表示词条位置。每轮示范与跟读共用从零开始的连续拍序，当前拍位为 `拍序 % 4 + 1`；跟读承接本轮示范已经占用的拍数，不重新从第 1 拍开始。例如示范 2 拍、跟读 2 拍时依次为“示范 1 → 2，跟读 3 → 4”；超过 4 拍继续循环，不为点亮方块而增加时长。新轮、新词、直接切词或重读从第 1 拍开始；普通暂停后继续保留原拍位，改速后的拍位读取按 §2 规则生效的编排。准备、恢复准备、口号与词间转场各自独立计拍，不改变原词条的轮次拍序；恢复准备的 1 / GO 完成后回到暂停位置。

界面区分“编排时长”和“实际用时”。前者不包括教师暂停、逐词等待和临时重读，编排目标也使用相同口径；后者从首个编排阶段开始计至结束，包含暂停、等待、临时重读和运行中资源等待，不含开始页测试及首批资源准备。开始页以“编排时长”标注，并提示“教师等待和暂停另计”，不将其称为上课结束倒计时。结束后显示实际用时、练习条数与重读次数，不生成学生正确率或掌握度。

练习条数按“完整完成过全部轮次的不同词条位置”计数；同一位置重读 / 循环不重复计，相同英文的不同位置独立计，跳过或中途结束不计完成。重读次数按教师主动执行重读的次数统计，暂停时仅定位也算一次，不据此评价学生表现。

结果页区分自然完成和主动提前结束，不以相同成功图标替代状态说明。自然完成的有限收束动效仅响应真实完成事件，不改变统计或重播时机；焦点及减少动态规则见视觉规范“首发游戏收束与特效生命周期”。重播清除旧反馈与统计，保留本次会话已生效设置；回到开始页恢复本课最后成功保存的本地设置；明确恢复原课件见 [15 · 本地保存与统一完成](15-课堂设置本地保存与统一完成.md)。

## 2. 课堂状态和教师控制

### 2.1 状态流转

打开 → 开始页 → 检查并准备资源 → 按 §1 顺序执行口号、准备、示范、跟读与转场 → 完成。运行可暂停。新课默认自动模式：开始后按课前编排连续完成各词轮次、跟读间隔、转场和跨段准备，无需手动下一词；学生发音不触发推进。教师可选逐词模式，非末词完成全部轮次后进入“等待教师”，主按钮“继续下一词”按原编排继续。末词完成后两种模式都不等待，直接播放已启用收尾，再按循环设置结束或回到开场。已有课件及主动保存的新课偏好沿用原模式。首次资源准备未成功时留在开始页；开播后资源错误暂停在待播阶段并提供修复 / 重试，不回到整课开头。

编排中的首段准备为 4 拍，依次显示 3 / 2 / 1 / GO；后续段准备为 2 拍，显示 1 / GO。可选恢复准备也按剩余拍数显示。倒数读取当前准备阶段的剩余时间与每拍时长，不另加时长或计时器；暂停时冻结，关闭舞台特效或减少动态效果仅停止装饰动画，倒数仍与真实拍位同步。资源加载不显示这套节拍倒数。

| 控制 | 精确行为 |
| --- | --- |
| 开始 | 用户点击后解锁音频播放权限，准备当前已启用声部的首批资源，不改变声部开关；禁止重复开始叠加音源 |
| 暂停 / 继续 | 记录播放位置，声音、节拍和画面同步停止；继续从原位置恢复；可选恢复准备 2 拍，默认关闭。恢复目标为等待阶段时，逐词模式保持等待，自动模式按原编排自然推进 |
| 自动 / 逐词 | 新课默认自动，按编排连续进入下一词；逐词模式仅在非末词完成全部轮次后等待，词内仍自动运行。播放词条时切换在本词结束生效，未暂停的其他阶段立即生效；等待中切自动，按原编排自然推进。暂停中只记录模式、不发声，继续时按当前模式恢复；末词按上述收尾与循环规则执行 |
| 上一词 / 下一词 | 取消旧声音，从目标词首轮开始；暂停时保持暂停、播放时继续；等待教师时上一词 / 下一词均立即开始目标词，按钮不越界；连续切词按目标索引连续更新，仅最后目标发声 |
| 重读 | 从当前词第一轮重新开始，完成后遵循当前模式；暂停时只定位不播放，等待教师时立即重读 |
| 改速 | 先校验新 BPM 下整课各条目，确保回切 / 循环也可运行；超过拍数范围等错误时保留原 BPM 和进度并定位原因。有效时，暂停中重算安排并保持暂停，点击继续后从当前阶段起点恢复；播放中从下一词生效，当前声音不变速。等待教师时保存已校验的待生效 BPM，继续下一词或主动切到其他词时生效；重读当前词沿用本词 BPM，待生效值继续保留，不按暂停规则重算 |
| 词义 / 展示模式 | 当场改变画面，不改声音和练习时间 |
| 结束 | 立即停止全部声音与待执行播放，显示结束页；重播从头建立新进度 |
| 循环 | 默认关闭；开启后整课完成再从开场开始，不重叠上一轮声音 |

开始页显示名称、词数、编排时长、声音模式、适用的推进方式、版本信息，以及“课堂设置 / 开始课堂”；HTML 额外显示导出时间。存在已启用声部时才提供“测试声音”：节拍启用则播放短节拍，语音启用则播放首个完整可用样本，音乐启用则播放短样本，不消耗课件进度；可停止测试，开始课堂先停止测试音源。全部关闭声音时直接说明按画面节奏练习，不显示无效试听按钮。单组、单词与准备拍垫的显示规则见 [课堂上下文与信息精简](13-课堂上下文与信息精简.md)。

开始页以关卡启动布局呈现摘要与操作，并以本课前三个实际词语组成能量装置悬浮卡。允许低速氛围运动，不产生教学拍击或开始计时；运行后的星尘爆发、冲击环和四拍反馈读取同一真实阶段与拍序。暂停、等待、后台、关闭特效及减少动态效果时停止装饰绘制，恢复不补播积压粒子。画面效果不新增音效声部、不改变声音权限或资源准备规则。

等待教师时主按钮显示“继续下一词”，空格执行相同动作：先播放当前词之后尚未执行的词间转场，或段间口号 / 后续段准备，再进入下一词。这些阶段仍按编排各执行一次；逐词等待只增加教师等待时间，不删改编排。等待期间节拍、语音和音乐均暂停，继续后恢复。

独立“上一词 / 下一词”按钮与左右方向键用于直接切词，从目标词首轮开始，跳过途经的转场、口号和准备，不补播；与“继续下一词”的自然推进明确区分。R 重读当前词。已暂停时空格只执行继续，按当前模式恢复，不额外切词。

可选的恢复准备只在继续实际练习时插入，不计入编排时长；恢复等待教师不插拍。临时准备中再暂停，继续只走剩余拍数，不反复插入新准备；切词取消临时准备并按目标词和当前暂停状态处理。

空词表不可开始，一条词可独立运行；词条练习及等待阶段，首词禁用上一词、末词禁用下一词，其他阶段遵循下表。键盘为空格播放 / 暂停、左右切词、R 重读、Esc 退出全屏；输入框、弹窗及原生按钮操作不重复触发全局快捷键。长按不连发播放和重读，不堆叠播放。

浮层打开时，Esc 先关闭允许关闭的浮层并恢复焦点，不同时触发课堂快捷键；没有浮层时 Esc 仅退出全屏。

运行中打开课堂设置会暂停；等待教师及异常状态保持原状态。设置在底部「完成设置」统一校验、保存并应用，音量试听不改变课堂进度，改 BPM 仍遵循表中生效边界。关闭设置不隐式开始、继续或切词。

所有适用数值统一检查：非法或待应用的输入阻止完成、开始及继续；收起不丢失草稿，可定位修正或明确放弃。完整校验、会话保留与弹窗布局规则见 [14 · 课堂设置校验与布局](14-课堂设置校验与布局.md)。

每词轮数可在课前或课中调整。课前通过完整编排校验后用于首次开始；课中即使暂停，也等进入另一词首阶段或重玩时安装，当前词及其重读维持原轮数。后续 BPM 调整与待生效轮数合并并使用相同边界，避免删除当前轮次。详情及保护规则见 [12 · 课堂轮数与设置说明](12-课堂轮数与设置说明.md)。

非词条阶段的按钮以实际阶段为准，暂停时保留同样目标但不发声；导航跳过的准备、转场和口号不在后台补播。

| 所处阶段 | 上一词 | 下一词 | 重读 |
| --- | --- | --- | --- |
| 开场口号 / 首段准备 | 禁用 | 首词 | 禁用 |
| 段间口号 / 后续段准备 | 上一段末词 | 待开始段首词 | 禁用 |
| 同段词间转场 | 刚完成的词 | 待开始的词 | 禁用 |
| 收尾口号 | 末词 | 禁用 | 禁用 |

示范、跟读或等待教师时，上一词 / 下一词按当前词索引定位相邻词，重读定位当前词；首末边界禁用相应导航。文字领读阶段显示“教师示范”，不显示正在播放示范音频。

失焦、页面隐藏或系统休眠时暂停；恢复后不自动发声，显示继续入口。全屏被拒绝可窗口运行，Esc 不结束课堂。编辑试听、预演与课堂只允许一个音频会话；切换课件或退出运行停止并释放旧会话。

## 3. 声音与资源

示范 / 口号、基础节拍、背景音乐为三个独立声部。示范与口号共用语音声部但分别可关闭；关闭示范同步切换文字领读。默认语音音量 100%、节拍 20%、音乐 15%；节拍开启；制作页新建课件在首发音乐仍在库时默认启用该音乐，旧课件不改写。底层无素材的规则模板仍保持音乐关闭。声音开关决定对应声音是否使用和打包：关闭口号移除对应阶段，关闭示范改用教师示范拍数；关闭节拍或音乐不改变阶段和编排时长。静音只影响播放音量，不改变启用状态和资源完整性。

声音模式与启用开关在备课时确定，课堂只调整音量或静音，不临时启用未打包的声部；改变模式须回编辑器重新检查并导出。手工录音不随系统音色 / 语速变化而重做；更换录音来源须明确选择。背景音乐启用后默认循环，整课循环仍默认关闭。

配音时音乐平滑降低至当前音乐音量的 30%，配音结束后恢复，过渡约 150 毫秒；跟读阶段不插入口号。音乐仅作背景，不自动分析节拍，不因音乐快慢改变练习；本地节拍是唯一节拍依据。

| 资源 | 规则 |
| --- | --- |
| 系统配音 | Windows 本地制作，保存实际音色、语言、语速、文件格式与真实时长；缓存复用，不实时在教室合成 |
| 替换录音 | MP3 / WAV，每项最大 20 MB、最长 30 秒；导入后解码、试听并记录对应文本版本 |
| 背景音乐 | MP3 / WAV 最大 50 MB、最长 10 分钟；另支持普通 MP4 / AAC-LC 原音轨提取（视频≤500 MB、输出≤50 MB），见06规范。可设循环，结束时停止；首发音乐为用户提供并确认的完整音轨 |
| 通用边界 | 仅接受可解码的音频数据，损坏、零时长或错误格式不能标记就绪；使用系统字体，不下载字体 |

播放以 Web Audio 时钟为准，画面读取相同时间位置，不用定时器触发次数累加。按当前及下一词滑动预加载所需示范 / 口号，末词运行期间同时预载后续收尾，避免正常自动播放停在收尾前；段落再长也不整段解码。保留正在播放及即将使用的解码数据，已不用的及时释放。解码缓存预算为 64 MB，按每声道实际采样点数 × 声道数 × 4 字节计；预算不足先释放非播放缓存，仍不足则延后下一项。单项自身超预算在准备检查中定位阻止，提示换用较小音频，不突破预算或无限等待。背景音乐单独按需播放，不计入该缓存，也不整曲预解码。

试听、预演和课堂共用上述资源检查与预算。准备检查使用实际音频采样信息，运行时再次按真实解码结果核对，不能只凭压缩文件大小或清单自报值判断；换电脑后的重采样也须复核。音乐检查采用媒体元数据和可播放性检查，不为验证而整曲解码。解码失败与超预算明确报错，不能当作仍在准备而无限等待。

待播声音未就绪时，暂停声音、节拍和进度并保留待播阶段；就绪后显示继续入口，从该阶段起点恢复，等待不计编排时长。背景音乐一次准备超过 30 秒仍未就绪时明确报错并释放失败资源，教师可主动重试，不无限加载或永久缓存临时失败。后台恢复重建调度。±100 毫秒同步目标指英文示范声音起点与对应画面阶段起点，不包含外接蓝牙等设备自身延迟。

## 4. 日常携带：单文件课堂 HTML

### 4.1 默认流程与支持范围

便携交付以课堂成果为单位：家中安装备课软件；日常上课只带 HTML；需要换机继续编辑时，再携带 `.ecglesson` 并在目标电脑安装备课软件。

**在家制作并预演 → 导出 → 打开实际成品检查 → U 盘 / 文件传输 → 复制到教室电脑 → Edge / Chrome 打开 → 测试声音 → 上课。**

课堂支持 Windows 10 22H2 / Windows 11 x64 的 Edge / Chrome 120 及以上版本，直接以本地文件打开；验收同时覆盖最低版本和发布时稳定版。无需安装备课软件、系统配音包或开发工具，无网络依赖和有效期，同一文件可每天反复使用，不依赖家中电脑开机。系统文件关联不是浏览器时，可右键“打开方式”或拖入浏览器。

HTML 包含当前游戏播放器、固定课件版本、已启用声音与音乐、样式、系统字体声明和必要归属信息。课堂文件必须可由浏览器直接打开；运行不得依赖 CDN、远程字体、跨文件模块加载、Service Worker（服务工作线程）或本地 HTTP 服务。只输出当前游戏所需内容，不把其他游戏和个人词库一并打入。

### 4.2 导出与成品检查

主动作“导出课堂文件”；可选“同时保存可编辑课件包”，默认关闭；“导出后打开检查”默认开启。默认检查当前草稿，只有教师明确选择才检查旧已准备版；HTML 始终检查所选运行版本：英文与参数有效、启用素材齐全且声音匹配、能解码、资源无越界引用。词义为空和超过目标时长只作提醒。当前草稿的教学错误不阻止已选择且检查通过的旧版 HTML 导出。

同时导包时，独立校验所固定草稿及存在时的已准备快照的结构、版本和全部声明 / 引用素材；草稿未完成的教学输入可保留，素材缺损仍阻止导包。包失败不使已通过检查的 HTML 失败，两种文件分别报告结果。

HTML 固定使用选定且检查通过的运行修订，可编辑包使用所固定的草稿及存在时的已准备快照；后续编辑均不混入。界面显示检查 → 打包 → 校验 → 保存 → 完成；先在本机生成成品，再向目标位置写入临时文件，重新读取并比较文件校验值，通过后才完成命名 / 替换并标记成功。外置设备突然断开时保留本机副本，提示重新复制与检查目标文件。HTML 与可编辑包分别报告结果，一项失败不把另一项已生成文件删除，也不显示“全部完成”。

复制失败后的“重新复制”只读取已生成本机成品，再校验并写入新目标；成品生成失败使用“重新导出”，重新展示并固定所选版本。离开结果页不取消正在执行的导出，不用返回操作暗示已经停止写入。

同时导出两种文件时，一次固定同一课件的草稿及存在时的已准备快照；HTML 使用选定且检查通过的运行修订，即当前草稿或教师明确选择的旧已准备版，可编辑包包含这组快照。目标临时文件与正式文件位于同一卷；覆盖采用原子替换，失败保留原目标和本机副本，不先删除旧文件。

默认文件名 `课件名_YYYY-MM-DD.html`；日期按当前电脑本地日期取值。过滤非法文件名字符，不改变内部课件标识；重名默认加序号另存，明确选择才覆盖。课堂文件大小上限 100 MB，即实际成品最多 100,000,000 字节，包含播放器、数据及声音编码后的全部内容，不能只相加原始音频大小；超限阻止保存目标成品，提供关闭音乐 / 更换较短音乐的定位入口；仍需拆分时提示复制课件后分别保留所需词条，不静默删教学内容或降配音质量。

导出前校验数据和素材，导出后验证成品清单及文件完整性；教师仍需在真实成品中试听开场、一个长词 / 短语和切词。点击“打开检查”打开目标实际文件，不用编辑器预览替代。声音模式在开始页可见，文字领读版不能显示“完整配音”。

### 4.3 随堂操作的保存边界

HTML 支持与桌面一致的教师控制、音量、展示和调速；「完成设置」将本课设置保存在当前浏览器本地，不改原文件。重新打开恢复最后成功保存的设置，播放从头开始；存储限制、过期检查及恢复原值见 [15 · 本地保存与统一完成](15-课堂设置本地保存与统一完成.md)。浏览器不提供完整词表编辑或重新配音。

课堂的能量装置、词序 HUD、四色拍垫、Canvas 星尘连线 / 拖尾 / 拍击爆发及 CSS 网格 / 光束随播放器一并内嵌，断网仍可显示，不加载外链图片、字体、特效库或在线预设。“舞台特效”控制装饰运动并随本课设置保存，不改变声音或编排；暂停、等待、页面隐藏及系统减少动态效果时的行为以 [视觉规范](02-页面交互与视觉规范.md#63-动效粒子与交互反馈)为准。Canvas 不可用时保留 CSS 场景、完整教学文字、真实拍位和教师控制，不阻止上课。

复制课堂 HTML 不会传输个人课件库；教师选择带出的教学内容本身会包含在文件中。原始课件继续保存在家中，日常只需带 HTML，需要换机编辑时再带可编辑包。

## 5. 可编辑包与换机

`.ecglesson` 是带清单的 ZIP 容器，含指定课件的草稿、存在时的最近可上课快照、相关素材与来源，不含无关课件、整个个人数据库和基础词库。允许导出尚未完成的草稿，但明确标为“可编辑草稿”，不能与可上课的 HTML 混淆。

导入顺序：选择文件 → 读取受限清单 → 预览名称、游戏、准备状态及游戏摘要 → 检查版本和资源 → 导入副本或打开已验证内容相同的既有修订。单词节拍摘要显示词数和编排时长，不适用的摘要项不显示。相同来源标识但内容不同也属于冲突，只能导入副本，不能覆盖。副本生成新标识并保留来源；已存在声音可直接用，新制作需选择目标电脑实际音色。具体双修订结构与相同内容判定见技术文档。

包清单和版本字段见[技术与数据规范](04-技术架构与数据规范.md#5-可编辑包格式与兼容)。单包最大 200 MB，解压总量最多 500 MB、最多 2,000 项，清单最大 2 MB，`lesson.json` 最大 10 MB。导入与导出使用相同限制，共享声音按实际打包文件计一次，内容、清单与归属文件均计入总量；解压过程中持续检查实际值，不只信任包头。拒绝绝对路径、`..`、符号链接、重复路径、外部资源地址和可执行文件，先提取到专用暂存目录，全部校验通过才入库。

路径按 Windows 规则统一检查正反斜杠、大小写及尾部点 / 空格；拒绝盘符、UNC / 设备路径、保留设备名和冒号数据流，规范化后重名也拒绝。每个最终绝对路径必须位于本次暂存目录内，不能借路径写到其他位置。

失败清理本次暂存，不破坏原文件或留下半份课件。U 盘只作传输，不直接运行正在编辑的数据库。完整备份用于恢复整个个人资料，可编辑包用于单课迁移，两者不混用。

## 6. 异常处理

| 异常 | 用户可见处理 |
| --- | --- |
| 示范声音缺失或过期 | 定位词条，更新 / 导入录音 / 明确切换文字领读；切换后继续检查口号等启用资源，不自动降级 |
| 口号声音缺失或过期 | 定位口号，更新 / 导入录音，或明确关闭受影响口号；不把切换文字领读视为已修复 |
| 音频设备 / 解码异常 | 首次准备失败留在开始页，未开始的练习不计时；开播后停止调度并保留失败阶段，提供测试声音、重试或设置入口，重试从该阶段起点恢复；修复前不自动继续 |
| 目标不可写、磁盘不足、U 盘拔出 | 区分生成失败与复制失败；已生成本机副本可另存重试，未校验不报成功 |
| 版本过高或当前软件不含该游戏 | 展示可读取的元信息及所需版本，提示使用包含该游戏的受支持软件版本，阻止运行和覆盖 |
| 包损坏、文件校验不符 | 指出受影响资源并阻止入库，不保存半成品 |
| 导出后继续修改 | 已导出文件保持原版本，重新导出才更新课堂内容 |
# 声音异常恢复显示约定（2026-10-21 二次复查）

课堂控制器的 `error` 是中断状态，舞台、反馈与主动作必须一致：保留当前词与真实进度，显示“播放已中断”，由教师主动重试当前阶段，不重新开场、不制造完成条目。首次准备失败仍停留开始页。设备故障以告警播报；重试成功后清除告警。设置打开期间故障信息在设置内呈现，关闭设置后原位置仍可重试。
