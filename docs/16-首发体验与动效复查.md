# 首发体验与动效复查

作者：ahui。产品版本保持 1.0.0。当前验收结果与限制见[验收记录](release-notes/validation-1.0.0.md)。

## 范围、依据与验收

注册表当前仅有「单词节拍」，包含配音跟读、文字领读、学生自主齐读。审查覆盖材料到课件的正向制作流程、公共导航和资源页面，以及三种模式的课前设置、开始、阶段推进、暂停恢复、导航重读、结束、重玩和退出。项目没有学生作答判定、计分或排行榜，对应的正确／错误答题效果不适用；不能为此次视觉复查新增教学规则。

本轮的智能辅助指本地词典与材料候选、预设与真实时长编排、手动／锁定值保护、可检查差异、声音复用和交付校验。装饰不表示分析进度或学习评价；界面应说明真实判断依据和教师可采取的下一步，不新增模型服务或聊天入口。

验收以实际操作为准：选中项不因无变化操作丢失；有实质影响的切换可取消；建议有明确操作名称且能定位真实对象；非法输入不能完成；本地设置只随本课依赖失效；声音试听遵循最新设置；三种模式和已有数据不改变教学含义。720×480、911×480、1366×768 下主要操作、英语词语和拍位可见，动效不阻挡操作。全特效的拍点文字提交与下一次浏览器绘制机会分别采样，保留原 100ms 显示延迟目标，减少动态结果不替代全特效结果。浏览器测量不能冒充物理显示器或音箱输出测量。
