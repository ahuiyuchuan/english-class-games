# 本地视频 BGM 导入

作者：ahui。版本1.0.0，2026-10-21。实现前约定；实际验证以交付报告为准。

## 范围与兼容

编辑器“导入音乐”和资源页“导入背景音乐”共用本地导入对话框，保留MP3/WAV；新增MP4容器中的AAC-LC音轨提取。提取原音轨，可能含人声和音效，不做AI分离、裁剪、变速、混音或音乐节拍分析。只处理音频，不解码画面，视频编码不作为音频兼容性的保证。加密、碎片化或不支持的音频编码明确拒绝。

沿用已依赖的Symphonia 0.5.5（MPL-2.0；准确的上游源码压缩包随安装包置于 resources/licenses/symphonia-sources），启用isomp4/aac功能并静态编入软件，不新增FFmpeg进程、PATH要求或联网步骤。解码器逐包处理，输出原采样率/原单声道或双声道PCM16 WAV，再走现有校验、内容寻址存储、试听、课件引用和离线导出。

## 操作和限制

1. 选择MP3/WAV/MP4，显示真实检查状态；取消文件选择不改变素材。
2. MP4按容器真实音轨显示编号、编码、语言及默认标记；单轨自动选中，多轨只有唯一启用/默认标记时预选，否则必须人工选择。绝不混合音轨。
3. 用户确认导入，显示不确定进度，可取消。成功进入现有音乐库；编辑器自动选中但不改变启用开关，资源页不修改任何课件。
4. 视频最大500MB；选中音轨最长10分钟；输出WAV仍受50MB限制（立体声长视频可能更早达到上限，明确拒绝而非截断）；最多双声道、192kHz。音频仍按原50MB/10分钟限制。视频解码循环在每个数据包边界检查120秒超时；检查和落盘另受上述大小限制。全局最多一个媒体导入。
5. 视频中的全零静音音轨拒绝并解释；无音轨、损坏、格式变化、解码错误、超限不会入库。读取原文件，绝不修改或删除原文件。

## 生命周期

操作采用检查→准备→确认入库两阶段。准备结果仅存放受管临时目录；取消、离页和卸载会取消准备并删除临时结果，不能迟到入库。入库是短事务阶段，按钮与关窗保护禁止打断；取消与确认按同一原生锁串行决定。重试重新检查，不复用失败结果。关窗保护期间不再接受新的音乐导入；如其他未保存表单取消关闭，则恢复导入入口。临时文件启动时清理。素材保存后不依赖原视频路径；重复操作被同步锁挡住，同内容可复用已收藏音乐。

## 默认音乐与桌面图标

用户指定第一个视频的完整无口播音轨作为首发BGM，来源记录为用户提供文件，不声称原创或可任意再许可。现有音乐音量、循环及启用开关语义不变；新建课件默认选中并启用这首音乐；旧课件及用户导入音乐时的启用状态保持不变。首次启动入库后允许用户删除，不在后续启动强行恢复。第二段只参考音乐运用，不复制页面或玩法。

安装器更新当前用户桌面快捷方式，使用安装目录内明确的品牌ICO路径，并通知Shell刷新。不删除用户其他快捷方式、不清空系统图标缓存；版本保持1.0.0。

## 验收

真实MP3/WAV及用户两份MP4；中文/空格/特殊字符路径；无音轨、静音、损坏、编码不支持、多轨默认/人工选择、大小/时长/输出超限、取消/重复/退出/关窗、成功后移除测试源。核对试听、音乐循环/音量/暂停/恢复/结束/重玩，HTML无服务器断网运行及课件包重导入；安装包中解码器和许可、快捷方式修复脚本与ICO均需核验。
