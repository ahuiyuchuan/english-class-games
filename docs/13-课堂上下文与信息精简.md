# 课堂上下文与信息精简

作者：ahui

## 范围与规则

本轮仅调整有实际证据的冗余显示与无效入口，沿用单词节拍主题、正式编排和三种练习模式，不删除教师数据，不改变准备、轮数、声音与换词规则。

- 分组数量与编排一致，只计算有词条的段落。只有一个有效组时，课堂页头和准备阶段不显示组号或组名；多组时页头显示当前位置，准备阶段保留教师命名。空段不产生虚假的组数。
- 准备、恢复准备的拍垫只表示真实准备拍，首段四拍、后续段及可选恢复准备两拍；不把组名、口号当作单词填入朗读词槽。示范、跟读、自主齐读继续显示原有词语；齐读每次两拍仍只触发一次朗读强调。
- 只有一个词时，隐藏前后词预告及其开关、无选择余地的词语下拉框、批量轮数面板和逐词推进选择。保留当前词轮数、锁定说明、撤销、暂停、重读、整课循环等有效设置。底部切词控制仍遵循编排导航：准备阶段可进入第一词，不能误删这个有效操作。
- 多词轮数批量范围只提供真实存在且与“全部词语”不同的分类；没有可调整项时保留手动／锁定原因，不能绕过保护。
- 全部声部关闭时，开始页直接说明“本课按画面节奏练习”；两个试听入口隐藏，不要求点击之后才告知无法试听。音量为零仍属于已启用声部，可在设置调大，不隐藏其入口。
- 结算只用统计卡展示实际时长、完成条目与教师重读，不在下方重复同样数字。齐读拍位在顶部显示一次，下方保留轮次和实际用时。
- 长课名和低高度窗口允许纵向滚动；键盘聚焦开始页按钮时预留滚动余量，保证完整可见。实测 701×480 时原按钮底部超出视口约 0.23 像素，不能通过放宽完整可见断言掩盖。

## 验收与证据

使用真实页面检查单组、多组（含空段）、单词、多词、无声音和有声音状态；三种模式及两种展示方式保留原教学内容。检查 720×480、911×480、1366×768，运行中倒数、暂停恢复、重读、结束与重玩；以单元测试验证语义和状态，以真实浏览器及离线成品验证布局和流程。
