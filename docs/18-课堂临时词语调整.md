# 课堂词语管理与练习安排

作者：ahui。2026-10-22。产品版本1.0.0。

## 范围与入口

课堂开始前及课中均可打开「课堂设置 → 练习安排」。左侧搜索和选择词语，中间编辑该词；同页提供按范围统一轮数和适用拍数。支持新增、删除、修改、组内排序与撤销，全部通过底部「完成设置」一起校验并保存本地，不分散保存。主要验收1920×1080，其他尺寸基本兼容。本模块的智能辅助指真实参数校验、时长、范围预览、声音匹配与锁定保护，不涉及模型、录音、识别或评分。

此前只允许修改现有词的英文／释义，不支持增删排序，已由用户本次明确要求替换。不将旧限制继续作为当前规则。按用户最后指示，新交付验收后删除releases内旧打包，只保留最新一套；开发验证和受保护源码基线仍保留。

## 每词设置与范围统一

- 可搜索英文／释义并选择词语，显示实际序号、轮数与拍数摘要。无搜索结果可清空搜索；单词课不放多词选择器，但保留新增和必要管理操作。
- 所选词直接编辑英文、释义、词语类型、重点标记、轮数，以及当前模式适用拍数。轮数1～8，新增均1轮。切换选词不擅自修改任何参数。
- 自主齐读总拍数1～32、每次占拍1或2，必须整除。4／2表示每轮4个基础拍、提示读2次，不能把两个朗读词块说成两拍。逐词提供「四拍读四次」明确设为4／1；不根据词长自动改节奏。
- 文字领读可设置教师示范与学生跟读拍数；配音跟读的示范时长来自实际录音，只读，允许设置学生跟读拍数。齐读隐藏不适用的示范／跟读参数但不删除。
- 右侧统一调整范围为真实存在的全部／普通／重点词，直接输入目标并显示实际修改与跳过数量。默认保留手动及锁定字段；教师可明确选择包含手动值，锁定始终保留。只切换范围不修改；未编辑项目保留原值；原始空白、越界或不整除时整次完成阻止，不提交部分词。
- 词语重点标记变化后，已经选择的范围仍明确可见；若该类变为0词，提示重新选范围，不能显示「全部词语」却暗中保留旧范围，也不能自动扩大修改对象。非法范围输入未修正时禁用增删、排序和结构撤销，避免减少到一词后将错误字段隐藏；父级完成校验不因词数减少而豁免非法输入。
- 界面区分每轮总拍数、每次朗读占拍、实际朗读次数和轮数，显示真实编排时长，不含教师等待。帮助按钮支持悬停、聚焦、点击，关键错误及影响不能只藏在帮助中。

## 词表管理与保护

英文trim后1～120个Unicode字符，释义trim后最多200字符可留空，均禁止控制字符。原始非法输入保留并就近说明；收起不能用旧值绕过保护。相同英文保留独立ID及教学义项，只提示，不自动去重。释义修订保留来源并标记教师修订。

新增用正式词条创建函数产生独立ID与默认参数，教师明确选择单词／短语；不复制旧词音频，不调用网络声音制作。原词保留ID、来源、音频与锁定。最多100词，删光时保留新增／撤销入口并阻止完成。搜索只过滤展示，不改变范围或词序。

本地新增词的身份始终相对原HTML课件判断，不因一次完成就变成原词。教师改变其单词／短语类型时，仅仍为预设的示范／跟读参数按明确类型重建默认；不根据英文空格推翻教师类型选择。原课件词的隐藏参数及已手动修改值仍保留，正式存储校验不放宽。

移动只在现有组内上移／下移，组边界禁用；不新增跨组口号或重排分组。位置锁定词不能移动、删除，其他操作也不能推移其原组内绝对位置。删除提供明确撤销，文字还原只退回最近完成的该词正文，不取消其轮数和拍数。

## 统一保存与运行边界

所有字段只在底部「完成设置」校验、正式编排、单键写入成功后才安装；保存失败保留草稿和旧课堂，可重试或明确仅本次使用。收起／Esc保留草稿，放弃恢复最近完成值。恢复课件原始设置须明确确认后清除当前课的本地记录。

课前完成立即用于首次开始。课中仅改文字、轮数、拍数时保持暂停，当前词和重读仍按原完整阶段；跨词或重玩才安装新安排。安装按稳定条目ID／索引定位，不用随全局编排序号变化的旧阶段ID误跳位置。

新增、删除或排序改变词表身份／顺序，完成前明确提示「完成后返回开始页，按新词表从头开始」；成功保存后取消试听、解除订阅、释放旧控制器／声音、清空待生效编排，再返回开始页。新旧词序不混用、不自动播放。保存失败不重置当前进度。重玩、回到开始页、刷新和关闭重开均使用最近成功保存的新词表。

配音跟读修改英文或新增无配音词时，正式声音匹配失败须阻止完成，不能显示新词却读旧词。可还原、删除新增项、回编辑器制作声音，或由教师明确把本课全部词改为文字领读；原配音保留，切回配音必须全部核验。文字领读和齐读不要求单词示范配音，启用口号仍完整检查。

修改／还原词表、切换课堂配音模式立即取消过期试听及准备，迟到结果不得播放旧候选或停止新试听；音量滑动继续使用既有实时混音。

## 本地v5与兼容

本地设置v5保存每词正文、轮数、齐读参数，增加分组内ID顺序与适用教学参数（类型、重点、示范拍数、跟读规则）。只认领课堂允许字段；新增词重建后不接受记录注入的声音、来源或锁定，原词锁定、音频、来源仍受保护。组ID及组顺序不变；ID唯一、1～100词与正式整课编排始终校验。

v1～v4按各自冻结结构及身份规则读取，旧版本仍禁止增删重排，不放宽旧schema；先严格恢复旧数据，再捕获为当前内存设置。读取不升级，完成才写v5。恢复结果按统一捕获函数规范化，避免键顺序不同造成假未保存。保留舞台特效和前后词预告偏好。

保留256KiB真实UTF-8上限、每课独立键、原课件及启用素材指纹。无关素材增删不令本课过期；当前原课件变化或损坏／未知记录则明确回退并保留旧记录，不静默清库。恢复成功普通提示4秒收起，异常警告持续，详见[课堂状态提示](19-课堂状态提示.md)。

产品1.0.0、课件包／运行协议不变，无新增依赖。课堂本地设置不写回原HTML、课件或音频；携带到其他电脑仍需编辑器修改并导出。旧HTML须重新导出或使用新版示例。旧核心遇v5明确不支持并回退原课件，不删字段伪装支持。回滚需从受保护源码基线重新构建并使用原课件，必要时明确恢复原课；不删除其他课或平台数据。

## 验收

三模式词表增删改查、组内排序、首末边界、空表、100词、位置锁、非法文本、重复词、配音缺失及显式领读；统一完成／保存失败／放弃／刷新／重开／重玩；课中结构改变释放旧任务并回开始页。4／1与4／2可见区别、选词独立拍数、范围统一、手动包含及锁定跳过、非法组合阻止完成。1920×1080真实file://断网HTML操作、截图与录像，最终打包并核对同一运行核心；未实际验证的硬件或环境范围单独说明。
