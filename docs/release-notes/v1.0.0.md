## English Class Games v1.0.0

面向高中英语课堂的 Windows 本地智能备课与离线游戏平台，贯通材料整理、教学内容确认、练习编排、声音制作、课堂预演和导出流程。免登录，教学资料保存在本机。

首发「单词节拍」包含配音跟读、文字领读和学生自主齐读。本版保留离线配音和断网安装能力，消除重复源码打包；完整桌面源码作为同版本独立附件提供，产品版本及教学规则保持1.0.0。

---

### 重点功能

- **材料整理与教学确认**：支持词表、表格及阅读选词，提供列用途、教学义项与短语候选；保留原文、来源和教师修订，不自动删词。
- **有依据的本地智能辅助**：根据词库、规则、真实音频及时间轴提供编排、时长建议和声音复用；展示依据与影响范围，保护手动值、锁定项及撤销，不把动画包装成智能分析。
- **单词节拍三种模式**：软件示范跟读、教师文字领读或学生直接跟拍齐读；新课每词默认一轮，可逐词及按范围调整轮数、拍数和朗读次数。
- **课前与课中设置**：支持临时词语增删改查、排序、轮拍及画面和音量调整，统一通过「完成设置」校验并在当前浏览器保存；非法输入阻止保存。
- **声音与音乐**：内置中英离线配音，支持录音、MP3／WAV及本地视频音轨导入；区分普通伴奏、音乐对拍和保音高变速，提供波形、测速、首拍与循环校准。
- **离线课堂与可编辑课件**：导出单文件 HTML 直接上课，`.ecglesson` 用于导入后继续编辑；支持暂停、重读、切词、全屏、结束与重玩，主要适配1920×1080。
- **清晰的许可与源码交付**：自有代码使用GPL-3.0-only，完整桌面源码独立提供；HTML仍内嵌播放器源码，第三方和教师素材保留各自权利。公开版示例节奏音为自制CC0-1.0音频。

### 快速开始

1. 下载下方 **English Class Games_1.0.0_x64-setup.exe**，安装并打开。
2. 进入「智能制作」，点「使用示例词表 → 整理并预览」，确认英文和释义后点「确认内容，下一步」。
3. 填写课件名称、选择练习模式，点「一键制作」，按提示处理真正阻断制作的问题。
4. 点「预演课件」，测试声音和节奏；需要调整时，在开始前进入「课堂设置」。
5. 返回制作，点「导出课堂文件 → 检查并导出」；需要以后编辑时，同时保存可编辑课件包。
6. 使用 Edge／Chrome 打开实际导出的 HTML，确认后复制到教室电脑即可断网上课。

完整操作步骤见[最快导出小游戏使用手册](https://github.com/ahuiyuchuan/english-class-games/blob/v1.0.0/docs/10-最快导出小游戏-使用手册.md)。

### 数据说明

- 教学材料、课件和设置默认保存在本机，不新增学生录音、发音识别或成绩评分。
- 安装器与软件源码不携带你的资料库。换电脑请使用资料库备份恢复，或携带HTML／可编辑课件包。
- HTML的课堂设置只保存在当前浏览器，不改写原文件；换浏览器、清理数据或移动文件后可能无法沿用。需要携带修改时，请在编辑器修改后重新导出。
- 普通伴奏的音乐与课堂BPM独立；对拍适用于教师校准后的恒速音乐，不把音量峰值当作节拍。
- 自有代码GPL-3.0-only允许商业使用、收费、修改与合规再分发，不自动改变教师词表、释义、录音、BGM及生成音频的许可；此前合法取得的MIT权利不能追溯撤销。
- 网络分发按GPLv3第6(d)条在同版发行页提供完整源码；通过U盘等物理介质转交安装器时，请同时携带本版本Source.zip。HTML自身保留可离线下载的播放器源码，课堂无需登录或联网。详见[许可与对应源码](https://github.com/ahuiyuchuan/english-class-games/blob/v1.0.0/docs/22-许可证与对应源码.md)。
