# 辅助能力、校准与音乐变速优化

作者：ahui。2026-10-21。产品保持 1.0.0；本文件是本轮实现与验收约定，不代表未执行的检查已经通过。

## 范围与问题基线

唯一注册游戏是单词节拍，三种练习模式不变。继续复用材料、候选来源、教师常用词、差异确认、锁定、撤销、任务、音频素材及离线导出。详见 `validation/platform-optimization/`，该目录保存修改前源码、文档、示例和构建配置副本（不包含资源目录的原始全量快照）；当前无 .git，不初始化仓库。

优先处理：自主齐读不适用声音控件和批量按钮；时长未知的真实原因；词典记录与独立义项的区别；双列用途建议；短语未收录说明；小屏编辑；完整特效显示延迟。后续增加可视校准与真正保音高变速，不改变拍数、朗读次数或教学内容。

## 材料与建议约束

无表头的恰好两列，只有各非空行均能明确区分拉丁字母英文与含汉字释义时，才提供列用途候选和依据。点击明确确认后才采用，原始行及重复项保持不变；混合／歧义列继续逐列选择。表头、分隔、编码仍可人工修正。

完整词典参考记录不能按一项记录宣称唯一教学义项。未拆分校对的多义释文仍需教师选择或改写，不自动按标点拆成可靠教学答案。未匹配完整短语表示当前词库未收录，不表示英语中不存在该短语；教师可将确认后的短语存入现有常用词库复用。

时长未知须区分参数／内容错误与真实声音缺失。建议空状态区分已在目标内、输入未完整、没有可调整的预设项及本次已忽略。显示目标、实际、差额，明确不含教师等待。所有接受操作仍进入现有差异预览及一次撤销；不自动改 BPM、删词或覆盖手动／锁定项。

整课拆分是独立的显式操作：按原词序贪心分组到目标时长，保留全部条目、手动值、锁定、段落归属及原课，先显示各课词语、真实时长和超目标项，再点击创建副本。只有真实编排可计算才提供方案；分组导致占位符口号音频失效时要求先处理声音，不能把失效声音算作可运行。部分保存失败保留成功清单，重试只创建未成功项，源输入改变后拒绝继续使用旧计划。

## 音乐变速方案

比较：媒体元素 `preservesPitch` 适合普通伴奏，但不提供采样级首拍和循环调度；直接调整 AudioBufferSourceNode 速率会改音高；实时 AudioWorklet 增加算法延迟、导航冲刷及 file 协议分发验证成本。本轮优先使用有界本地预处理，处理后复用现有 AudioBufferSourceNode 与课堂同一时钟。音乐原素材始终保留，不写回原文件。预处理不可阻塞主线程，取消／退出终止处理，错误不静默回退为不保音高。

采用算法为 SoundTouchJS 当前 TypeScript 核心 `@soundtouchjs/core` 2.1.1（MPL-2.0），依赖同版本 Lanczos 模块；仅在核验实际包内容和真实音频测试后采用。旧 `soundtouchjs` 0.3.0 是 LGPL-2.1，不混淆两者许可。已实际验证0.75、0.9、1、1.1、1.2、1.25倍的PCM时长、440Hz音高及file://真实Worker播放；不把离散测点说成所有音源音质保证。

数据含义：原始 BPM 保留在既有 `music.sync.bpm`；目标课堂 BPM 是课件 BPM；倍率是目标／原始 BPM。普通伴奏的音乐倍率独立于课堂 BPM。首拍和循环起止均保存为原音频毫秒，处理后播放位置除以倍率。保音高默认开启，关闭时明确允许音高变化。预处理结果只在会话内复用，退出释放；素材内容、倍率、保音高、算法版本变化使缓存失效。运行中不做不连续的热切换，修改在重新准备课堂时生效，并明确说明。

## 可视校准

精确毫秒输入继续保留，波形时间轴使用秒刻度，并显示当前指针／拍点网格。波形仅代表振幅，不代表拍点。点击位置或试听当前位置可标记首拍；敲击测速根据教师间隔提供候选及不稳定提示，不假称自动识别音乐。整拍循环建议显示完整拍数与秒数，教师确认采用。试听可以从选定位置或循环区间开始；改校准即时停止旧预览，原始非法输入不丢失。

## 模型边界与依赖选择

规则助手准确标为本地辅助，不冒充大模型。未配置可用模型时现有备课／课堂完整工作；外部材料发送必须明确启用。真实模型输出必须结构校验、范围核对、过期保护并由教师确认，不能写库或执行命令。当前本机 Ollama 探测不可用，真实模型验证必须单独报告限制。

可选本机模型入口融入编辑器建议区：仅连接固定 `http://127.0.0.1:11434`，教师先检测服务、选择已安装模型并明确允许发送本课统计和自然语言需求。请求不发送词表正文、音频、学生信息或密钥。模型只返回三种现有预设之一及理由，经结构验证后，由现有预设规则生成真实差异；不直接应用或覆盖锁定／手动值。请求60秒超时，可取消；课件修订变化立即使结果失效，重新请求。服务不可用时禁用生成，保留全部本地功能。Ollama 的安装、模型下载和本机服务 CORS 配置由使用者管理，不随课堂包分发，不开放联网模型服务。

已核对参考仓库：wavesurfer.js（BSD-3-Clause）可借鉴波形／区间交互，简单有界波形优先原生 SVG；motion（MIT）和 tsparticles（MIT）不重复引入，沿用现有 CSS／Canvas；Vercel AI 与 Ollama 仅作为模型适配参考，模型运行时不得成为离线课堂依赖。具体采用包版本、许可、成本及测试结果在交付记录补充，不能以 GitHub 元数据替代包内许可。

## 验收与兼容

三模式及旧课件保持原行为；新增变速设置缺省为 1 倍／保音高。含变速能力的新课件提升内部运行协议，旧运行核心明确拒绝，不删除字段降级；产品仍为 1.0.0。可编辑包保留设置和原素材，HTML 共用运行核心且无 CDN／开发服务器依赖。

分别测量音频调度、音频数据拍点与画面 DOM 延迟，报告采样数、持续时间、P95、最大值和漂移。完整特效要求最大显示延迟 <100ms；降级和减少动态独立统计。真实音乐音质听觉、干净 Windows 与原生界面操作若无可用环境须明确未验，不能以模拟或截图替代。

构建检查只扫描当前源码与测试，受保护历史基线不参与 lint；Vite 依赖入口固定 index.html，避免扫描历史独立 HTML。桌面 CSP 仅额外允许上述固定本机 Ollama 地址，不开放任意联网接口。

长流程复测发现完整特效64拍最大145ms，尚未通过100ms。拍位改变采用同帧同步提交，避免 React 并发调度让必要文字状态排在装饰工作后；仅真实可见状态变化提交，不改变音频时钟或关闭效果。

装饰层保持原数量与效果，使用 paint containment 和独立合成层隔离 Canvas 重绘，避免大面积星尘刷新使教学文字和环轨一起重绘；只在现有边界内部裁剪，不改变课堂布局。

合成层尝试实测反而增加软件渲染成本，已撤回。环轨保留旋转、颜色与父环静态光晕，移除旋转伪元素逐帧的大面积 drop-shadow；效果种类、粒子数及拍位反馈保持。

课堂轮询与装饰绘制分离：16ms定时唤醒只读取同一AudioContext时钟，不累加时间、不生成另一套拍点；隐藏／失焦仍立即暂停，卸载清除唯一轮询。解决装饰帧率低时rAF连带延迟教学状态的问题。

应用端旧自动化仍使用第三模式加入前的“示范方式”标签，按现行“三种练习模式”的真实控件更新定位；不为测试恢复过时产品文案。

普通媒体路径实测发现load()会把playbackRate复位到defaultPlaybackRate，须同时设置默认倍率并在canplay后确认应用，不能仅检查编辑数据。校准试听同样设置默认倍率。修复后以真实媒体源频谱核对1.2倍仍为440Hz附近，再重建交付。
