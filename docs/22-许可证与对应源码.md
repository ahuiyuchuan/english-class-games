## 实际交付方案

Windows通过下载分发时按GPLv3第6(d)条，在同一公开发行页提供同版本完整对应源码附件，不要求安装器重复内嵌源码。源码无需账号即可取得，不额外收费；安装器保留精确附件地址、版本、大小和SHA256。通过U盘等物理介质转交时，须按第6(a)条同时携带该源码ZIP；仅复制EXE不能代替源码交付。HTML仍实际内嵌自己的播放器源码，不采用需要后续联系或访问私有仓库的书面承诺。

- Windows安装包保留许可、第三方声明及 `resources/source/desktop-source.json`、`SOURCE-ACCESS.txt`，关于页可打开本版本源码附件及本地版本／校验说明。`English-Class-Games-v1.0.0-Source.zip`独立提供完整自有原始源码、锁文件、构建／安装／控制脚本、前端依赖源码、Rust依赖源码及配音对应源码。安装器不再收录完整桌面源码ZIP，也不单独重复收录配音构建源码；离线模型、运行库与WebView2离线安装器保持完整。
- 每个新导出HTML内嵌 `portable-source.zip`。开始页的“许可与源码”可下载原始源码ZIP、查看GPL全文和第三方声明；进入课堂后收起，不遮挡词语或打断练习。源码包包含生成该播放器的原始TS／TSX／CSS及构建配置、依赖源码和锁定版本，不是压缩JS或source map的替代物。
- 可编辑包只保存课件数据与素材，不携带播放器可执行代码；`license.txt`明确区分软件与教学内容，不把整包内容改为GPL。重新导出HTML时由当前软件附带其对应播放器源码。
- 对应源码包不包含教师数据库、密钥、私人素材、Git历史、安装缓存或本机验证记录。构建工具与系统库可按说明另行安装，许可不要求把通用开发工具当项目代码分发。

备课软件保留一份随前端资源编入程序的播放器源码ZIP，按需读取以供断网导出，不再在安装资源目录重复放一份；不把源码Base64打入应用主脚本。HTML中的源码是非执行数据，点击下载时才解码。打包使用校验过的运行资源暂存目录，按清单排除开发源码，完整开发目录及第三方原始文件不被删除或改写。

SheetJS保留v0.20.3对应原始bits／modules、Makefile和控制清单；其xlsx.js、xlsx.mjs及LICENSE与锁定的@e965/xlsx发行文件逐字节一致。原始上游标签对象与实际commit分开记录，不把标签对象摘要误写为源码commit。

开始页许可入口与快捷键放在同一辅助区；展开的长文本内部滚动，不挤占课堂主要操作。许可源码数据块不执行脚本，不改变课堂的网络禁用策略。桌面源码也保留ONNX Runtime所需源代码，不能只因其原许可为MIT就把它遗漏在配音组合的源码之外。

构建先生成固定输入文件清单和SHA-256，再构建播放器，将播放器脚本／样式摘要与源码ZIP摘要写入产物收据。源码自身不收录生成的ZIP、运行核心或收据，避免循环包含。源码改动后必须重建，不能把旧ZIP和新二进制混用。正式交付清单同时核对安装包、独立源码ZIP、HTML和可编辑包；公开安装器前必须验证精确源码附件可取得且摘要一致。离线交付目录把安装器与源码放在同一介质。

Tauri在Rust编译阶段即解析随包资源，因此对应源码、许可及精简运行资源暂存生成放在beforeBuildCommand中，不能等到beforeBundleCommand才生成。直接使用Cargo构建时，先执行前端构建与pnpm notices:native；该命令同时生成运行资源和源码获取说明。桌面开发启动也先准备，确保首次源码构建不依赖旧暂存。暂存清单逐文件校验，不以取消许可／声音完整性检查换取体积缩小。

## 构建、核验与边界

源码ZIP解压后按 `CONTRIBUTING.md` 使用PowerShell7、Node24／pnpm11、Rust及Windows C++工具链构建。前端／便携构建无需配音模型；桌面完整打包需同一交付的配音资源，先用 `pnpm resources:prepare -- --archive <本地归档>`校验恢复。资源来源地址只用于溯源，不是对应源码的唯一获取途径。源码包中保留第三方源码的原始编码和版权。

配音源码包括实际DLL对应的ONNX Runtime 1.28.2 CPU源码和官方CMake锁定依赖归档，逐一验证上游SHA1并另记SHA256。保留CPU推理构建所需源码／脚本，省略可选训练、其他语言绑定和测试数据；选择与原始归档摘要记入source-lock.json。构建说明见resources/tts/licenses/BUILDING.md。资源恢复预算为512MiB，容纳模型、运行库和随附源码，不代表允许任意解压内容；仍逐路径、大小和摘要核验。上游C++运行库的完整重编译若未完成，必须在当前验收记录中明确，不以适配器编译代替。

官方仓库为https://github.com/ahuiyuchuan/english-class-games。Windows完整源码的精确获取地址为同版Release的Source.zip附件，不是仓库主页或GitHub自动生成的源码快照；HTML保留内嵌源码。安装、配音、备课、导出与课堂不需要联网，只有主动下载独立完整源码、打开项目链接及检查更新需要网络；离线取得完整桌面源码需同时携带附件。产品／数据／运行协议保持1.0.0及原行为，不迁移教师资料库。

验收包括：主许可一致、第三方字节未误改、实际包内许可和源码、从HTML离线下载源码、课件包往返、源码解压后适用构建、关于页键盘与布局、格式／静态／类型／测试／原生及安装构建。实际命令和结果记入当前交付验收记录，未完成或受环境限制不标通过。
