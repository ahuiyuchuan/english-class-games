# 课堂拍数与朗读次数复查

作者：ahui。产品版本保持 1.0.0。

当前课堂词语管理已使用本地设置版本5，详见 [课堂临时词语调整](18-课堂临时词语调整.md)。本文版本3为拍数功能阶段的严格兼容协议；当前新完成写5，读取1～4不改写，不能据本文历史版本号重新写回3。

## 已确认事实与本轮范围

当前只注册单词节拍，包含配音跟读、文字领读、学生自主齐读。自主齐读示例的最后一个短语 `take part in` 是每轮 4 拍、每次朗读占 2 拍、1 轮，正式时间轴为 100 BPM 下的 2.4 秒；底部两块代表两次朗读，不代表只有两拍。不能把短语静默改成四次朗读，也不能根据字符长度自动改规则。本阶段最初的问题是可见拍位没有解释两块与四拍的关系，课堂设置遗漏齐读节奏参数入口；该缺失已修复，后续完整词语管理见文档18。

本轮复用现有 chorus、chorusGapBeats、正式编排与音乐位置映射，不新增玩法、评分、录音或模型。AI 辅助继续指本地规则校验、真实时长、影响范围、手动／锁定保护与明确反馈。保留现有主题及特效，并重新实际检查三种模式、公共页面与离线交付，历史通过不算本轮通过。

## 行为与设计约定

- 设置的「练习安排」统一呈现选定词、轮数和模式适用参数。自主齐读可逐词调整每轮总拍数（1～32）及每次朗读占用拍数（1 或 2），展示「每轮 4 拍 · 读 2 次 · 每次 2 拍 · 共 1 轮」及真实编排时长；原有两种模式不出现齐读专属输入。
- 延续全部／普通词／重点词的实际范围，拍数与轮数共用同一选词和范围，分别紧邻排列。齐读的总拍数和每次占拍始终可见，直接编辑即表示调整，不再先勾选。未编辑时显示该范围的真实共同值，混合值明确为「各词不同」；只切范围不修改安排。只有教师实际编辑的批量字段参与调整，每字段可「还原」取消该项统一目标；清空数字仍是非法输入，不能解释为取消。先显示真实变化和保护数量，逐字段保留手动／锁定值，不因修改一字段覆盖另一个字段。不满足整除或受保护值导致不兼容时，整次完成阻止，说明对应词和原因，不提交部分结果。
- 空白、小数、越界及不能整除的组合保留原始输入，原位说明；同一词的总拍数与占拍可一起修正。收起／重开保留草稿，未处理错误阻止完成、开始和继续；恢复只丢弃对应未完成输入。逐词明确修改标为手动值，锁定字段在课堂保持只读；提供最近一次齐读安排撤销，不能越过锁定。
- 齐读的「词间间隔」提供 0～4 拍整数，0 表示连续换词，不是每轮间隔或准备拍；单词课不显示无实际作用的间隔控件。原始间隔保存且不影响另外两种模式。
- 所有字段仍只由底部「完成设置」统一校验、编排、保存和安装，无分散应用。课中改变总拍数、每次占拍、轮数或词间间隔同样推迟到下一词／重玩，当前词和重读保留已开始的安排；暂停、等待和错误状态不会因完成设置自动开播。与待生效 BPM 合并，不能相互覆盖。
- 舞台保留英文词块；把「基础拍」与「朗读次数／每次占拍」用可见摘要区分。每次占 2 拍时词块只在朗读开始强调，第二拍仅更新基础拍位；超过 4 拍继续使用窗口与完整进度，不堆 32 框。两种展示保持中央英语和释义优先。
- 词槽角标明确为「第 N 次」，槽内显示实际拍号刻度，基础拍高亮来自真实拍位，不重复触发朗读开始。逐词输入与批量预览分开记录字段归属：只改占拍后取消统一总拍，不能留下已取消的总拍值。每次完成有实际变化时更新上一份已完成快照，轮数与齐读撤销均回到最近一次提交前，不一直回退到第一笔。
- 复用统一帮助按钮、焦点、按压及减少动态规则。关键错误与生效时机常驻，不能只藏在悬浮说明中。720×480、911×480、1366×768 检查设置滚动、固定完成按钮、词块和控制区。

## 本地保存与兼容

本地偏好增加逐 ID 的齐读两项 RuleValue 和词间间隔，独立本地版本升为 3；课件字段、运行核心兼容版本、产品版本不变。保存保持同一键与 256 KiB 上限。读取 v1／v2 仍按各自原指纹严格核对，缺失的新课堂偏好从原课件继承；不把旧记录解释为默认 4／1 而覆盖教师既有短语设置。下一次明确完成才写 v3。逐条验证 ID 集合、锁定状态、来源、整除及正式整课编排；原对象不修改。

三种模式均保留齐读字段，但只有自主齐读允许课堂修改并校验 1～32、每次 1／2 拍、整除及 0～4 拍间隔。其他模式只允许逐字段原样保留原课件中有限数值、来源及锁定，包括尚未适用于齐读的隐藏组合；不能借浏览器存储改变隐藏规则，也不能因为隐藏组合非法而阻止原本合法的配音／文字领读保存。切回自主齐读仍须在编辑器按正式规则核验。所有版本的结构、有限数值、ID 完整性与独立锁定校验不因隐藏而放宽。

旧程序不认识 v3 时说明使用原课件设置，保留记录；回滚使用保留的旧安装包与原课件，必要时明确恢复本课原始设置。课堂本地偏好不写回编辑器、原 HTML 或可编辑包；永久修改及导出仍使用编辑器。桌面预演及新导出 HTML 共用实现，不依赖原视频路径或联网服务。

## 验收与证据

复现当前末词 4／2 与 4／1，对照真实四个基础拍和两次／四次朗读开始。覆盖 1、8、32 拍，非法 3／2、空白及越界，1／8 轮、手动／锁定与范围、批量只改启用字段、撤销、保存重开及 v1／v2 继承。检查 0～4 间隔、自动／逐词、暂停恢复、导航、重读、首末词、结束重玩、连续完成及多项待生效合并。

重新运行三种模式、两种展示、相关公共页面和离线 HTML，检查控制台、动画及粒子生命周期；全特效同步仍以既有 <100ms 标准测量，不以减少动态替代。物理投影／音箱输出若未测明确标记。适用格式、静态、类型、单元、浏览器、原生和构建记录以本轮实际结果为准。

本轮整合后第一次独占全特效64拍实测，DOM更新最大21.33ms，但下一rAF观测最大112.67ms，尚未达标，原始失败样本保留。应区分状态提交与显示帧的开销，使用独立诊断定位布局、绘制或合成成本后再最小修复；不得通过关闭全特效、删掉必要拍位、降低100ms阈值或只报告后续成功样本消除该失败。若正式视觉源码改变，重新生成课堂核心、HTML及安装包，并复验受影响流程和独占同步。

### 全特效合成成本修复约定

独立 trace 显示正常播放主线程布局／提交较短，逐帧光栅与合成成本更突出；诊断不是正式性能验收。保留原遮罩、仅提升 Canvas 图层或取消词块阴影插值未显示足够收益，不采用这些推测性改动。仅去掉动态全屏 Canvas 的 CSS 遮罩，下一 rAF 的64拍 P95／最大降为47.33／56.67ms；改用独立静态中央柔暗层后为50.67／67.33ms，三尺寸同状态截图和运行录像确认主体可读、装饰与控制可达。

据此只调整共用课堂舞台CSS：Canvas不再参加逐帧全屏遮罩合成，在装饰容器内以静态径向渐变保护中央英语／释义的阅读对比；柔暗层不接收输入，不进入教学布局，不盖住上层题目、词槽、按钮或弹窗。星尘、音符、移动网格、环轨、真实击拍、完成效果、生成数量与生命周期均保留，系统减少动态和暂停规则不变。不修改音频、时钟、拍数、教学参数、公共素材或兼容字段。

正式代码改变后重新生成共享核心及四个离线示例，实际复验三模式／三尺寸和10项特效测试，再在无并发构建／测试的窗口完成全特效两次及减少动态一次独立64拍量测。所有失败与诊断样本保留，正式收据明确区分修改前失败、诊断A/B与修改后正式结果；物理扬声器与显示像素延迟未测，不把下一rAF当成物理输出。
