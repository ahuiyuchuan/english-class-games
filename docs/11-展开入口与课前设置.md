# 展开入口、制作进度与课前设置

作者：ahui。2026-10-21。产品版本 1.0.0；先记录实施约定，实测证据保存在 `validation/disclosure-classroom-review/`。

## 问题与统一处理

- 全部 18 处原生 details/summary 入口使用共享样式：整行边框按钮、方向箭头、明确展开／收起提示、悬停和键盘焦点。保留原生 Enter／空格行为及受控条目状态，不以普通 div 替换语义。窄表格允许标题换行，不挤压教学内容。
- 声音任务的 completed 只统计成功（包含缓存），失败另存 failures。进度条表示“已处理＝成功＋失败”，不是成功率、耗时或 AI 分析百分比；分别显示成功、失败及未处理。总量未知使用不确定进度；取消、失败、中断保留真实进度，不补到 100%。制作向导、编辑器、任务中心及工作台共用该组件。制作中时长显示“声音准备完成后计算”，完成后显示真实编排或具体阻断原因。结果统计压缩为概要，零值不占独立大卡片。
- 课堂原先只在 started 后开放设置，而且未创建控制器时推进／循环／调速操作不生效。开始页与课堂均提供设置；课前设置必须进入首次控制器与试听。课中打开设置暂停，关闭不自动发声，由教师继续。

## 课堂会话规则

面板按节奏与推进、画面、声音分组；标题与关闭保持可达，内容独立滚动，720×480 不横向溢出。提供自动／逐词、整课循环、非对拍 BPM、展示方式、释义、舞台特效、邻词预告、适用声部音量及课前声音测试。恢复前两拍准备可在课前选择，沿用现有时间轴规则；开局后该项只读，避免修改正在恢复的临时阶段。

设置不改原课件，完成后保存在当前浏览器本地。课前 BPM 通过整课编排校验后更新摘要和首次开局；对拍音乐保持已准备的目标 BPM，明确返回编辑调整，不能只改画面。非法输入保留并就近提示，不默默纠正。所有设置在「完成设置」统一保存，声音测试可试听草稿。邻词预告只隐藏装饰导航，不改变中央词语、朗读词槽或真实拍位。单词课件的邻词预告及其他不适用入口按[课堂上下文规则](13-课堂上下文与信息精简.md)隐藏。重玩及返回开始页保留最后成功保存的设置，详细边界见 [本地保存与统一完成](15-课堂设置本地保存与统一完成.md)。

## 验收及回滚

检查展开／收起、Enter／空格、焦点、嵌套条目及 720／911／1366 宽布局；任务排队、运行、成功、部分失败、取消和未知总量；课前修改后开始、暂停、设置关闭、继续、重玩、回开始页；三个模式及便携 HTML 共用行为。任务组件状态测试不冒充真实语音合成测试。

没有新增依赖或数据字段，不改变声音缓存、教学拍数和兼容协议。无 .git，修改前源文件副本、编码／换行与 SHA-256 已保护；通过副本可回滚源代码，旧安装包原样保留。React／TypeScript／Rust 项目沿用现有规范，Java 框架及 MyBatis 规则不适用。

## 智能体验约束

本轮不新增大模型入口。智能体验体现为适用设置、真实制作与复用反馈、阶段引导和明确下一步。制作中的有界光轨只表示任务正在执行，不代表进度或识别能力；停止、失败或取消即停止运动。完成摘要区分可直接导出与需要修复。课前说明依据实际模式与会话配置更新，不生成虚构评价。

## 本轮结果

后续轮数入口与悬浮说明扩展见 [课堂轮数与设置说明](12-课堂轮数与设置说明.md)：支持课前逐词及受保护的范围调整，课中调整从另一词或重玩生效。以下测试数量仅属于本页原交付，不代表后续改动已验证。

405 项单元测试通过；47 项应用浏览器用例经受影响用例复验全部通过，23 项便携用例经暂停规则同步后全部通过。具体首轮失败、修正原因、复验日志、原生课件包往返及安装包证据见 `validation/disclosure-classroom-review/交付复查记录.md`。课前设置入口位于开始页右上，避免低高度挤压启动操作。没有新增模型入口、依赖或课件字段。
