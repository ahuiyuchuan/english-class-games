# 高中单词节拍示例

作者：ahui。

当前本地交付的examples目录中有可直接打开的HTML，editable-lessons中有对应可编辑包。每个HTML内嵌播放器对应源码，开始页“许可与源码”可离线下载；软件GPL-3.0-only，教学内容及素材保留各自权利。

在 Windows 10 22H2 / Windows 11 x64 用 Edge / Chrome 120 及以上版本打开 HTML，先点“测试声音”，再开始课堂。
文件可复制到另一台电脑断网使用，无需安装备课软件；三套示例均为自动推进与节奏方块。
开始后按编排连续练习至完成，无需手动下一词；空格暂停 / 继续，课堂设置可选逐词等待教师。

| 文件                                  | 用途                                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `高中单词节拍-配音跟读.html`          | 6 个高中词语，包含英文示范、中文开场与收尾；编排以开始页实际摘要为准（新建默认每词一轮），不含暂停和临时重读 |
| `高中单词节拍-文字领读.html`          | 相同词表，教师示范，无语音口号；编排以开始页实际摘要为准，保留节拍                                           |
| `高中单词节拍-学生自主齐读.html`      | 无示范阶段，每轮4拍，短语每次占2拍；编排16.8秒                                                               |
| `高中单词节拍-学生自主齐读.ecglesson` | 可继续编辑齐读拍数、轮数及音乐设置                                                                           |
| `高中单词节拍-配音跟读.ecglesson`     | 在备课软件中导入并继续编辑，包含对应录音                                                                     |
| `高中单词节拍-文字领读.ecglesson`     | 在备课软件中导入并继续编辑                                                                                   |

配音版使用 Windows 已安装的桌面音色预先制作的 WAV，并按“导入录音”绑定；实际音色见来源清单。
它展示已有录音的使用与携带；当前备课软件也内置离线中英配音，新制作无需另装系统音色。只有明确选择Windows系统音色时才要求对应WinRT音色可用。
示例不录制或评价学生发音。

三套示例均内嵌自制课堂节奏音，默认音量15%并循环；示范/口号播放时自动降低背景音乐。音频由振荡器与固定种子噪声合成，CC0-1.0，100 BPM、64拍、38.4秒，无外部采样。来源、精确网格与校验值见 `../resources/music/README.txt` 和 `source.json`；可编辑包也携带该音乐。三套示例使用普通伴奏，不强制课堂BPM联动；对拍须明确启用并试听。

## 开发者重建与核对

Git中保留源录音，恢复配音资源并构建便携核心后可直接重建示例；生成的HTML和课件包通过本地交付目录提供。仅重新录制源录音时，才需要已有en-US／zh-CN SAPI桌面音色；录音脚本只读取已安装资源，不安装音色、不修改注册表或教师资料库。

```powershell
pnpm resources:prepare -- --archive <本地Desktop-Resources.tar.gz路径>
pnpm build:portable
node scripts/build-examples.mjs
node scripts/build-tempo-example.mjs
```

`source-audio/source.json` 记录实际文本、音色、生成时间与 WAV 校验值。
`validation/artifacts.json` 记录三套产物的大小、SHA-256 与编排信息；身份映射由产品游戏模块生成，供原生导入验证。
身份清单的 `lessonSha256` 校验包内 `lesson.json` 正文字节，`artifacts.json` 的 `packageSha256` 校验整个 ZIP；示例日期固定为源录音生成时间以便重复构建，不代表最近一次构建时间。
HTML、课件包和这些清单均为生成产物，修改规则、播放器或声音后应重新生成，不手工改产物。

## 保音高变速校准示例

`单词节拍-保音高变速校准.html` 可直接断网打开，对应 `.ecglesson` 可导入编辑。使用明确标注的合成测试音：原始120 BPM、首拍125毫秒、循环125～2125毫秒，目标144 BPM（1.2倍）。第二词每轮4拍、每次2拍，仍只读2次。由 `node scripts/build-tempo-example.mjs` 生成，不把测试音称为真实音乐。普通伴奏见三种模式示例；校准可随课件复制复用，保留素材引用和每课自己的设置。

课堂设置统一点底部「完成设置」后保存在当前浏览器，关闭重开、回到开始页和重玩可恢复。不修改 HTML 或课件包本身；移动文件、换浏览器／电脑或清理浏览器数据不保证沿用。可在设置中「恢复课件原始设置」。开始页支持全屏，运行底部可直接结束课堂。
